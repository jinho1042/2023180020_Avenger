# 픽셀아트 AI 프롬프트 (캐릭터 · 적 · 보스 · 투사체)

> 대상: PixelLab, Retro Diffusion 같은 픽셀아트 전용 AI.
> 파일 경로·셀 크기·프레임 수의 기준은 [스프라이트_명세.md](스프라이트_명세.md)다.

## 0. 사용 순서

1. 캐릭터마다 **기준 이미지(idle 1프레임)** 를 먼저 만들고 마음에 들 때까지 다시 뽑는다.
2. 기준 이미지를 참고 이미지(reference)로 넣고 나머지 애니메이션을 하나씩 만든다.
3. 도구에 크기·프레임 수 입력칸이 있으면 프롬프트보다 **입력칸을 우선**해서 채운다.
4. 저장 파일명은 각 표의 `파일` 칸 그대로 쓴다.

### 공통 스타일 (모든 프롬프트 앞에 붙이기)

```
pixel art, side view, facing right, transparent background,
dark 1px outline, limited palette, no shadow, no text, no glow effects,
feet at the bottom center of the frame, same position in every frame
```

### 애니메이션 요청 틀

```
[공통 스타일]
[캐릭터 설명]
Animation: [동작 설명], [N] frames in a single horizontal row,
each frame [W]x[H] px. Same character as the reference image.
```
