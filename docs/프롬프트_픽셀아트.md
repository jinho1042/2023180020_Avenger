# 픽셀아트 AI 프롬프트 (플레이어 · 적 · 정예 · 보스 · NPC · 투사체)

> 대상: PixelLab, Retro Diffusion 같은 픽셀아트 전용 AI.
> 기준: `개발문서v3.5.md` (6장 플레이어, 10장 적, 11.4 보스, 2.5 NPC, 14.5 아트) · `config.py`의 몸 크기(`w`, `h`)와 색(`color`).
> 배경·타일·기믹 오브젝트·아이템·아이콘은 [프롬프트_범용AI.md](프롬프트_범용AI.md).
> 이미지 연결은 T19에서 한다. 그 전까지 코드는 도형으로 그리므로, 파일은 아래 경로에 모아 두기만 하면 된다.

## 0. 공통 규칙

### 0.1 파일 규칙

| 항목 | 규칙 |
|---|---|
| 형식 | PNG, 투명 배경 |
| 시트 | 애니메이션 하나가 파일 하나. 프레임을 왼쪽에서 오른쪽으로 가로 한 줄 (여백 없음). 도구가 격자(2×2 등)로만 내보내면 그대로 둔다. 스크립트로 자른다 |
| 시트 크기 | `가로 = 셀 너비 × 프레임 수`, `세로 = 셀 높이` |
| 방향 | **오른쪽을 본다.** 왼쪽은 코드가 뒤집는다 |
| 기준점 | 땅 위 캐릭터는 **발바닥이 셀 맨 아래 가운데**. 공중 캐릭터(박쥐, 수정 유생 등)는 **몸 중심이 셀 가운데**. 모든 프레임에서 같은 위치 |
| 몸 크기 | 표의 `몸` 칸이 판정 크기다. 몸통이 그 정도를 차지하게 하고 남는 칸은 무기·동작용 |
| 크기 오차 | 조금 어긋나도 된다. 셀에 맞게 자르고 늘리는 스크립트를 따로 만든다. 도구 최대 크기가 작으면 **절반 크기로 뽑고** 나중에 2배 확대(nearest)한다 |
| 파일명 | 각 표의 `파일` 칸 그대로 |

### 0.2 그림에 넣지 말 것 (코드가 덧그린다)

- **흰색·빨간색 번쩍임, '!' 표시** — 적 공격 예고 전용이다 (14.5). 적·보스 몸에 순백색이나 선명한 빨강을 넓게 쓰지 않는다.
- 피격 깜빡임, 그로기 약점 빛, 균열(보스 체력 단계), 그림자, 글자, 이펙트 파티클(흙먼지, 공기 점, 패링 섬광).
- 투사체는 캐릭터 시트에 그리지 않는다. 7장에서 따로 만든다.

### 0.3 공통 스타일 (모든 프롬프트 앞에 붙이기)

```
pixel art, 2D side view, facing right, transparent background,
dark 1px outline, limited palette, chunky readable pixels,
no shadow, no text, no glow effects, no white or red flashes,
original character design, underground ancient ruins setting
```

> 다른 게임 이름을 넣지 않는다 ("in the style of ..." 금지). 이 게임의 그림은 오리지널이어야 한다.

### 0.4 애니메이션 요청 틀

```
[공통 스타일]
[캐릭터 설명]
Animation: [동작 설명], [N] frames in a single horizontal row,
each frame [W]x[H] px. [기준점 문장]
Same character as the reference image, same size and proportions.
```

- 기준점 문장: 땅 위 = `feet at the bottom center of every frame, same position in every frame` / 공중 = `body centered in every frame`.

### 0.5 작업 순서

1. 캐릭터마다 **기준 이미지(`idle` 1프레임)** 를 먼저 뽑고 마음에 들 때까지 다시 뽑는다.
2. 기준 이미지를 참고 이미지로 넣고 나머지 애니메이션을 하나씩 만든다.
3. 도구에 크기·프레임 수 입력칸이 있으면 프롬프트보다 **입력칸을 먼저** 채운다.
4. 2페이즈 시트(`p2_` 접두)는 1페이즈 `idle`을 참고 이미지로 넣고 "same character, but [변화]"로 요청한다. 2페이즈 시트가 없으면 코드가 색만 바꾸므로 **선택**이다.

### 0.6 우선순위 (`SCOPE = 'full'` 기준, 15.1 순서)

1. **필수**: 플레이어, R1·R2 적(갱도 벌레, 박쥐, 갑각 전사, 가시꽃, 포자 버섯, 덩굴 매복충), 갑각 대장, B1, B2, 보름·하르·오람, 투사체 `thorn`
2. **권장**: R3·R4 적, 신전 골렘, B3, B4, B6, 나머지 투사체
3. **선택**: R5 적, B5, 숨은 보스, 2페이즈 시트, 실종 광부·연습 석상
