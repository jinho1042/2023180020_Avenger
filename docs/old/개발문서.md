# Avenger 개발문서

> 이 문서는 Claude Code(CLI)가 읽고 바로 구현할 수 있도록 작성한 개발 명세다.
> 기획 원본: `Avenger_게임기획서.pptx` (19장). 기획과 이 문서가 다르면 **이 문서가 우선**한다.

## 0. 작업 규칙 (Claude가 매 세션 지켜야 할 것)

1. **한 세션 = 한 작업.** 9장 작업 목록에서 체크 안 된 작업 중 가장 앞의 것 하나만 진행한다. 끝나면 체크(`[x]`)하고 멈춘다.
2. 작업 시작 전 관련 파일만 읽는다. 프로젝트 전체를 훑지 않는다.
3. **모든 수치는 `config.py`에만** 둔다. 다른 파일에 숫자를 하드코딩하지 않는다 (0, 1, 좌표 계산용 상수 제외).
4. 모든 이동·타이머는 `game_framework.frame_time`(초)을 곱하거나 더한다. 프레임 수로 시간을 세지 않는다.
5. 에셋(이미지·사운드)이 없으면 **도형으로 대체**한다 (`draw_rectangle`, 단색 이미지). 에셋 때문에 작업을 멈추지 않는다.
6. 작업이 끝나면 `python main.py`로 실행 가능한 상태를 유지한다. 실행 확인 방법을 사용자에게 한 줄로 알려준다.
7. 커밋은 사용자가 요청할 때만 한다. 커밋 메시지는 한국어, `[1주차] 플레이어 점프 구현` 형식.

## 4. 공통 구현 규칙

### 4.1 프레임워크 (2DGP 수업 방식)
- 모드 모듈은 `init / finish / update / draw / handle_events / pause / resume`을 가진다.
- `game_framework`: `change_mode`, `push_mode`, `pop_mode`, `quit`, `frame_time`.
- `game_world`: `add_object(o, depth)`, `remove_object(o)`, `update()`, `render()`, `add_collision_pair(group, a, b)`, `handle_collisions()`, `clear()`.
- 객체 인터페이스: `update()`, `draw()`, `handle_event(e)`(플레이어만), `get_bb() -> (l, b, r, t)`, `handle_collision(group, other)`.

### 4.2 레이어 (depth)
`0 배경 · 1 맵/발판/문 · 2 적·투사체 · 3 플레이어 · 4 이펙트 · 5 UI`

### 4.3 좌표와 충돌
- pico2d는 **좌하단 원점, y 위쪽 증가**.
- AABB 충돌. 지형 충돌은 **X축 이동 → X 충돌 해결 → Y축 이동 → Y 충돌 해결** 순서로 분리한다.
- 발판(one-way): 위에서 떨어질 때(`vy <= 0`이고 이전 프레임 발바닥이 발판 위)만 착지. 아래·옆에서는 통과.
- 공격 판정은 몸 hitbox와 별개의 **공격 hitbox**를 공격 활성 프레임 동안만 생성.

### 4.4 히트스톱
- `systems/hitstop.py`에 전역 타이머. 히트스톱 중에는 `play_mode.update()`에서 월드 update를 건너뛰고 이펙트·카메라만 갱신한다.
- 슬로모션은 `frame_time`에 배율(예: 0.3)을 곱한 값을 월드에 전달.

## 5. 플레이어

### 5.1 조작
| 키 | pico2d | 동작 |
|---|---|---|
| ← → | `SDLK_LEFT/RIGHT` | 이동, 방향 전환 |
| Alt | `SDLK_LALT` | 점프 (누르는 동안 상승, 떼면 `JUMP_CUT`) |
| A | `SDLK_a` | 공격 3연타 |
| S | `SDLK_s` | 패링 |
| Space | `SDLK_SPACE` | 대시 |
| Esc | `SDLK_ESCAPE` | 일시정지 (`push_mode(pause_mode)`) |

### 5.2 상태 머신
`Idle, Run, Jump(공중), Attack1, Attack2, Attack3, Parry, ParryStun, Dash, Hit, Dead`

- 공격 중 S/Space 입력 시 Parry/Dash로 **캔슬** 가능.
- 공중에서 공격·패링 가능 (공중 상태를 따로 두지 말고 `on_ground` 플래그로 처리해도 됨).
- 입력 버퍼: 공격·패링 입력은 `INPUT_BUFFER` 동안 저장했다가 현재 동작이 끝나면 실행.
- Hit: 피격 후 `INVINCIBLE_ON_HIT` 무적 (깜빡임으로 표시).
- Dash: `DASH_TIME` 동안 무적, 중력 무시, 수평 이동.

### 5.3 공격 3연타
- Attack1 → Attack2 → Attack3. 각 타가 끝난 뒤 `COMBO_WINDOW` 안에 A를 누르면 다음 타.
- Attack3는 넉백 `ATTACK3_KNOCKBACK`.

## 6. 패링 시스템 (핵심, 가장 신경 쓸 것)

### 6.1 적 공격의 단계
모든 적 공격은 아래 4단계를 거친다.
1. **Telegraph**: 적 몸이 번쩍인다. 흰색 = 패링 가능, 빨간색 = 패링 불가(+‘!’ 아이콘). 최소 `TELEGRAPH_MIN`.
2. **Windup**: 공격 모션.
3. **Active**: 공격 hitbox 활성. 이 시점에 판정한다.
4. **Recover**: 후딜레이.

### 6.2 판정
- S 입력 시 플레이어는 `PARRY_WINDOW` 동안 `parry_active = True`.
- 적 공격 hitbox(또는 투사체)가 플레이어에 닿았을 때:
  - `parry_active`이고 공격이 **패링 가능** → **성공**
  - 그 외 → 피격 (경직 중이면 피해 × `STUN_DAMAGE_MULT`)
- `parry_active`가 끝날 때까지 아무것도 막지 못했으면 **헛입력** → `ParryStun` `PARRY_FAIL_STUN`.

### 6.3 성공 시
- 히트스톱 `HITSTOP_PARRY` + 화면 흔들림 + 흰 섬광.
- 근접 공격: 적은 `Stagger` 상태 `ENEMY_STAGGER_TIME`, 받는 피해 × `STAGGER_DAMAGE_MULT`.
- 투사체: 방향 반전, 소유자를 플레이어로 바꿈 → 적에게 피해 × `REFLECT_DAMAGE_MULT`.
- 보스: `posture += 1`. `POSTURE_MAX` 도달 시 Groggy `GROGGY_TIME` + 슬로모션 `GROGGY_SLOWMO`, posture 0으로.
- `PARRY_COOLDOWN`을 즉시 0으로.
- 강화 훅 호출: `upgrades.on_parry_success(player, target)`.

## 7. 적과 보스

### 7.1 공통 AI (`enemy_base.py`)
`Idle → Chase → Telegraph → Windup → Active → Recover → (Chase)`
어느 상태든 패링당하면 → `Stagger`. HP 0 → `Dead` (파티클 + `HITSTOP_KILL` 후 제거).

각 공격은 데이터로 정의한다:
```python
Attack(name, parryable: bool, telegraph, windup, active, recover, damage, hitbox)
```

### 7.2 일반 적
| 적 | HP | 행동 | 공격 |
|---|---|---|---|
| 플라잉 몹 | 20 | 공중 배회, 플레이어 위로 이동 | 급강하 돌진 (흰색). 패링 시 즉시 격추 |
| 근거리 병사 | 40 | 접근 | 베기 2연타 (흰색), 확률적으로 방패 돌진 (빨간색) |
| 원거리 궁수 | 30 | `keep_distance` 유지, 근접하면 후퇴 | 화살 (흰색, 반사 가능) |

### 7.3 보스
**중간 보스 · 대검 기사** (HP 400, 느리고 묵직)
| 패턴 | 예고 | 내용 |
|---|---|---|
| 내려찍기 | 흰색 | 정직한 단발 공격 |
| 회전 베기 | 빨간색 | 광역, 대시로 회피 |
| 돌진 찌르기 | 흰색 | 먼 거리에서 빠르게 접근 |

**최종 보스 · 쌍검 기사** (HP 600, 2페이즈)
| 패턴 | 예고 | 내용 |
|---|---|---|
| 4연속 베기 | 흰색 | 리듬에 맞춰 연속 패링 |
| 순간이동 기습 | 빨간색 | 플레이어 뒤로 이동 후 베기 |
| 검기 발사 | 흰색 | 반사하면 큰 피해 |

- HP 50% 이하 2페이즈: 공격 속도 × 1.2, 페이크 동작(예고 후 공격하지 않음) 추가, 빨간 예고 비율 증가.
- 패턴 선택: 거리 기반 가중치 랜덤, 같은 패턴 3회 연속 금지.

## 8. 진행 · 강화 · 맵 · UI · 연출

### 8.1 방 (`systems/room.py`)
- 한 화면(1280×720) = 한 방. 스크롤 없음.
- 진입 시 문 잠김 → 적 전멸 → 문 개방 → 플레이어가 문에 닿으면 다음 방.
- 템플릿 JSON:
```json
{ "name": "platform_01", "type": "발판형",
  "platforms": [[x, y, w, h, "solid|oneway"]],
  "spawns": [["flyer", x, y], ["archer", x, y]],
  "player_start": [x, y], "door": [x, y] }
```
- 템플릿: 평지형 · 발판형 · 협곡형 · 혼합형 (일반 6종 목표) + 보스 아레나 2종.
- 같은 런에서 템플릿 중복 금지.

### 8.2 강화 (`systems/upgrades.py`)
- 시점: 전투1 클리어 후, 중간 보스 처치 후. 무작위 3개 제시(카테고리별 최소 1개), 1개 선택. 이미 가진 것은 제외.
- 각 강화는 `apply(player)` 또는 훅(`on_parry_success`, `on_attack`, `on_dash_end`)으로 구현.

| 카테고리 | 강화 |
|---|---|
| 패링 변형 | 판정 +0.05초 · 패링 성공 시 검기 발사 · 반사 투사체 피해 2배 · 패링 성공 시 체력 5 회복 |
| 기초 스탯 | 최대 체력 +30 · 공격력 +20% · 3타째 피해 +50% · 피격 무적 +0.3초 |
| 유틸리티 | 2단 점프 · 대시 거리 +50% · 대시 쿨타임 −30% · 대시 후 첫 공격 피해 2배 |

### 8.3 UI
- HUD: 좌상단 체력 바, 그 옆 획득 강화 아이콘, 우상단 대시 쿨타임 원형, 하단 중앙 보스 체력 + 자세 게이지.
- HUD는 가장자리에만 배치한다 (예고 번쩍임을 가리지 않게).
- 화면: 타이틀(시작·조작법·종료) / 강화 선택(카드 3장, ←→ + Enter) / 일시정지 / 결과(도달한 방, 패링 횟수, 플레이 시간).

## 10. 알려진 함정

- pico2d 키 이벤트: 누름은 `SDL_KEYDOWN`, 뗌은 `SDL_KEYUP`. 좌우 동시 입력은 누름 상태를 따로 저장해서 처리.
- `get_time()` 기반 `frame_time`이 첫 프레임에 매우 클 수 있다. 최대 0.05초로 제한한다.
- 히트스톱 중에도 이벤트는 받아서 입력 버퍼에 저장한다 (입력 씹힘 방지).
- 객체를 순회 중에 `remove_object` 하지 않는다. 제거 목록에 모았다가 update 끝에 제거.
- 이미지 경로는 `os.path.join(os.path.dirname(__file__), ...)` 기준으로 잡아 실행 위치에 흔들리지 않게 한다.
