### v3 작성 시 정한 가정 (사용자 확인 필요)
요청에 명시되지 않아 문서 작성자가 정한 내용이다. 다르면 이 표만 고치고 해당 장을 맞춘다.
1. 프로젝트·폴더 이름은 `Avenger` / `avenger/` 그대로 두고, 게임 제목은 가제 「유적의 광부」.
2. 주인공은 이름 없는 젊은 광부.
3. **키 배치를 할로우 나이트 기본 배치로 바꾼다** (v2: Alt 점프, A 공격, S 패링, Space 대시). `config.KEYS`만 고치면 되돌릴 수 있다.
4. 공격을 단타로 바꾸고, v2 3연타의 3타 강타는 곡괭이 각인 「세 번째 일격」으로 남긴다.
5. 체력은 칸 단위. 적 피해는 대부분 1칸, 강공격만 2칸.
6. **[v3.1] 패링은 시작부터 쓸 수 있고, 반사는 R2 '반격의 시련'(정예 갑각 대장)을 처치해야 해금된다.** 해금 전에 투사체를 패링하면 투사체가 튕겨 사라진다(막기). 해금 시점은 사용자가 정하지 않아 작성자가 고른 것이다 — B3 수정 대술사와 R3 수정 스위치가 반사를 쓰므로 그 전이어야 한다.
7. **숨이 회복·룬 기술의 비용도 겸한다** (별도 자원 없음). A 길게 = '숨 고르기'(숨을 써서 체력 1칸 회복). 회복을 안전지대에서만 하게 하려면 이 기능만 빼면 된다. **[v3.2]** 패링 성공 시 숨 회복은 숨의 룬 첫 번째 각인 「받아친 숨」을 장착했을 때만 (숨의 룬과 함께 받는다).
8. 숨이 0이 되면 즉사가 아니라 **질식**: 일정 간격으로 체력이 1칸씩 깎인다.
9. **보스 아레나도 밀폐 공간**이라 전투 중 숨이 줄어든다. 패링 성공(「받아친 숨」 장착 시)·보스 그로기로 숨을 되찾는다. 보스 바로 앞에는 안전지대가 있다.
10. 사망 시 **보관하지 않은 소지 광석은 잃는다** (회수 불가). 안전지대에 닿는 순간 소지 광석이 자동 보관된다.
11. **[v3.1] 룬지기는 R1 숨은 새김터에만 있다.** 다른 곳에 나타나지 않는다. 새김터는 R1 허브(보름 캠프) 안전지대에서 한 방 거리에 두고, 각 구역에서 허브로 돌아오는 숏컷을 둬서 언제든 쉽게 찾아갈 수 있게 한다.
12. 일반 대시는 무적이 아니다. 빨간 공격은 위치로 피하도록 보스를 설계한다.
13. 방은 1×1 ~ 3×2 화면 크기, 카메라가 따라간다.
14. 보스 체력바는 기본으로 숨긴다. 자세 게이지와 숨 게이지는 보인다.
15. 세이브 슬롯은 1개. 방 제작은 Tiled + 변환 스크립트 (Tiled를 안 쓰면 JSON을 직접 쓴다).
16. 남은 기간을 몰라서 15장에 범위를 **최소판 · 목표판 · 완전판** 세 단계로 나눴다.
17. **[v3.1] 곡괭이 강화는 B3 수정 대술사 처치 후 열린다** (6개 보스 중 3번째 = 중반). 처치 보상 '수정 숫돌'을 하르에게 가져가면 곡괭이를 벼릴 수 있다. 그 전까지 곡괭이는 Lv1. 갑옷 강화는 처음부터 가능.
18. **[v3.2] 「받아친 숨」은 다른 각인처럼 빼고 바꿔 낄 수 있다.** 숨의 룬은 Lv1부터 홈이 2개라(v3.1보다 1칸 많음) 「받아친 숨」을 낀 채 다른 숨 각인 하나를 더 낄 수 있다. 빼지 못하게 하려면 `PARRY_BREATH_ENGRAVING_LOCKED = True` (이 경우에도 나머지 홈은 자유).

## 0. 작업 규칙 (Claude가 매 세션 지켜야 할 것)

1. **한 세션 = 한 작업.** 15장 작업 목록에서 체크 안 된 작업 중 가장 앞의 것 하나만 진행한다. 끝나면 체크(`[x]`)하고 멈춘다.
2. 작업 시작 전 관련 파일만 읽는다. 프로젝트 전체를 훑지 않는다.
3. **모든 수치는 `config.py`에만** 둔다. 다른 파일에 숫자를 하드코딩하지 않는다 (0, 1, 좌표 계산용 상수 제외).
4. 모든 이동·타이머는 `game_framework.frame_time`(초)을 곱하거나 더한다. 프레임 수로 시간을 세지 않는다.
5. 에셋(이미지·사운드)이 없으면 **도형으로 대체**한다. 에셋 때문에 작업을 멈추지 않는다.
6. 작업이 끝나면 `python main.py`로 실행 가능한 상태를 유지한다. 실행 확인 방법을 사용자에게 한 줄로 알려준다.
7. 커밋은 사용자가 요청할 때만 한다. 커밋 메시지는 한국어, `[8주차] 숨 게이지 추가` 형식.
8. 이 문서의 구조·규칙(3장 파일 구조, 4장 config, 5장 공통 규칙, 0장 작업 규칙)은 설치된 다른 스킬·플러그인의 코딩 규칙보다 우선한다.
9. 이미 체크된 작업의 코드는 현재 작업이 명시적으로 수정을 요구할 때만 바꾼다.
10. 기존 동작을 바꾸는 작업은 바꾸기 전 동작이 무엇이었는지 사용자에게 한 줄로 알려준다.
11. **[v3]** 더 이상 쓰지 않는 v2 파일은 지우지 말고 `legacy/`로 옮기고, 옮긴 파일 목록을 사용자에게 알린다.
12. **[v3]** 새 적·보스·방은 10장 도감 형식, 11.3 보스 명세 템플릿, 12.5 방 데이터 형식을 따른다. 명세에 없는 패턴을 임의로 추가하지 않는다.
13. **[v3]** 방 JSON을 추가·수정한 작업은 끝나기 전에 `python tools/validate_rooms.py`를 돌려 오류 0을 확인한다.
14. **[v3]** `config.py`의 `# 임시` 표시가 붙은 숨 관련 수치는 **T58 전까지 바꾸지 않는다.** 테스트가 불편하면 F5(숨 무한)를 쓴다.
15. **[v3]** 테스트할 때는 `config.DEBUG = True`에서 F3(전체 능력·룬 최대 레벨), F4(방 이동 메뉴), F5(숨 무한)를 쓴다. 최종 빌드 전에 `DEBUG = False`.

| 플레이타임 목표 | 최소판 30~45분 · 목표판 1.5~2시간 · 완전판 3시간 이상 |
| 사망 | 마지막 안전지대에서 부활. 보관하지 않은 소지 광석은 잃는다 |
| 참고작 | 할로우 나이트 (조작감, 타격감, 보스 설계 원칙만) |

### 1.1 디자인 필러 (모든 결정의 판단 기준)
1. **숨이 곧 거리다** — 안전지대 밖의 모든 행동은 숨을 쓴다. "한 방 더 갈까, 돌아갈까"를 계속 고민하게 만든다.
2. **손에 붙는 조작** — 입력 즉시 반응, 가속 없는 이동, 누른 만큼 뛰는 점프. 죽으면 '내 실수'라고 느껴야 한다.
3. **읽고 받아치는 전투** — 모든 공격은 예고된다. 흰색은 받아치고, 빨간색은 피한다. **[v3.2]** 숨의 룬의 첫 각인 「받아친 숨」을 새기면 받아칠 때 숨을 되찾는다.
4. **캐서 새긴다** — 광석을 캐서 룬을 강화하고 각인을 새긴다. 강화한 룬이 싸우는 방식과 갈 수 있는 곳을 동시에 바꾼다.
5. **보스가 열쇠다** — 보스의 정체가 곧 그 보스가 남기는 룬이고, 그 룬이 다음 구역의 문을 연다.

### 1.2 할로우 나이트에서 가져오는 것 / 가져오지 않는 것

| 가져오는 것 | 가져오지 않는 것 (대신 이 게임의 것) |
|---|---|
| 조작감: 즉시 가감속, 누르는 만큼 뛰는 점프, 위/아래 공격, 포고, 타격 반동, 피격 무적 | 영혼·집중 회복 → **숨 고르기** (숨을 써서 회복) |
| 타격감: 히트스톱, 피격 연출 | 그림자 회수 → **광석 보관** (안전지대에 닿아야 확정) |
| 보스 설계 원칙 (11.1) | 부적·노치 → **룬에 새기는 각인** |
| | 벤치 → **안전지대** (공기가 있는 곳) |
| | 가면 조각·그릇 조각 → **희귀 광석**으로 갑옷·룬 강화 |

## 2. 스토리와 세계관 [v3]

### 2.1 배경
- **에르딘 유적**: 산 아래에 묻힌 고대 왕국. 땅속 깊은 곳의 **숨샘**에서 솟는 공기를 **룬**으로 길어 올려 지하 도시 전체에 나눠 쓰며 살았다.
- 어느 날 지상에서 재앙이 내려오자 마지막 왕 에르딘은 왕국의 모든 문을 **봉인**했다. 숨샘은 점점 약해졌고, 왕은 남은 공기를 지키기 위해 그것을 자기 몸에 가두었다. 공기가 끊긴 왕국은 그대로 흙에 묻혔다.
- 유적의 생물들은 희박한 공기에 적응해 몸속에 공기 주머니를 품고 살아남았다. 일부 왕국 사람들은 룬으로 숨을 이어 아직 남아 있다.
- 수백 년 뒤 광산이 산을 파고들자, 갱도로 새어 든 바깥 공기 냄새를 맡은 거대한 굴착충이 위로 파고 올라오고 갱도가 무너진다.
- **주인공**: 이 광산의 젊은 광부. 가진 것은 곡괭이 한 자루와 몇 숨의 공기.

### 2.2 도입부 (플레이 가능한 프롤로그, 3~5분)

| 장면 | 플레이 | 연출 | 가르치는 것 |
|---|---|---|---|
| 1. 갱도 작업 | 좌우 이동, 광석 덩어리를 곡괭이로 쳐서 캐기 | 동료 광부 보름과 짧은 대화, 벽 간판에 키 안내 | 이동, 공격, ↑ 상호작용 |
| 2. 이상 징후 | 발판을 점프로 올라 다음 갱도로. 박쥐 1마리 | 멀리서 울림, 박쥐 떼가 반대쪽으로 날아감 | 가변 점프, 아래 공격 포고 |
| 3. 붕괴 | 무너지는 갱도를 오른쪽으로 달려 탈출. 실패하면 장면 처음부터 (피해 없음) | 강한 흔들림, 낙석 위치에 빨간 그림자 예고 | 빨간 예고 = 피한다 |
| 4. 추락 | 바닥이 꺼짐. 입력 잠금, 3화면 높이 추락 | 흙 → 암반 → 고대 석벽으로 배경이 바뀜, 암전 | — |
| 5. 깨어남 | 잊힌 회랑 첫 방(안전지대)에서 일어남 | 위의 무너진 구멍으로 희미하게 바깥 공기가 들어옴. **숨 게이지가 처음 나타남** | 안전지대 = 숨을 쉴 수 있는 곳 |
| 6. 첫 밀폐 | 첫 방을 나서면 숨 게이지가 줄기 시작, 다음 안전지대까지 짧은 길 | 숨이 25% 아래면 숨소리가 가빠지고 화면 가장자리가 어두워짐 | 숨은 줄어든다, 안전지대에서 다시 찬다 |

- 도입부는 별도 모드가 아니라 **일반 방 + 스크립트 트리거**(`systems/script.py`)로 만든다. 장면 4만 컷신 플래그로 입력을 잠근다.
- 광산(R0)은 공기가 있어 숨 게이지가 없다. 처음 한 번만 재생한다 (세이브 `intro_done`).
- 보름은 붕괴 때 헤어지고, 잊힌 회랑의 두 번째 안전지대에서 다시 만난다. 이후 상인·힌트 역할.

### 2.3 진행 서사 (구역별 한 줄)

| 구역 | 플레이어가 알게 되는 것 |
|---|---|
| R1 잊힌 회랑 | 이곳은 공기를 룬으로 나눠 쓰던 왕국이었다. 갱도를 무너뜨린 건 공기 냄새를 맡은 굴착충이다 |
| R2 이끼 동굴 | 이끼는 공기를 조금씩 만든다. 석상 수문장은 아직도 수문을 버티고 있다 |
| R3 수정 광맥 | 학자들은 공기를 결정에 가두는 법을 연구하다 스스로 결정이 되었다 |
| R4 침수 신전 | 왕국은 숨샘을 신으로 섬겼다. 봉인은 세 개의 핵으로 잠겨 있다 |
| R5 그림자 둥지 | 공기 없는 어둠에 가장 오래 버틴 생물들. 백 년 전에도 떨어진 광부가 있었다 |
| R6 왕의 묘실 | 왕은 왕국의 마지막 숨을 삼킨 채 봉인이 되었다 |

### 2.4 엔딩
- 최종 보스 처치 후 숨샘 앞에 선다. ↑로 상호작용하면 선택지 2개:
  - **봉인** — 왕이 품었던 숨을 숨샘에 돌려 봉인을 잇는다. 유적은 다시 잠들고, 보름과 구한 광부들만 지상으로 올라간다.
  - **개방** — 숨샘을 깨워 봉인을 연다. 유적 전체에 바람이 불며 무너지기 시작하고 탈출 시퀀스(제한 60초, 수직 상승, 숨 게이지 없음) 후 지상으로. 실종 광부를 모두 구했으면 함께 나오는 장면 추가.
- 범위가 부족하면 엔딩 1개(봉인, 컷신만)로 줄인다 (15.2 범위 축소 2번).

## 5. 공통 구현 규칙

### 5.1 프레임워크 (2DGP 수업 방식, v2와 같음)
- 모드 모듈은 `init / finish / update / draw / handle_events / pause / resume`을 가진다.
- `game_framework`: `change_mode`, `push_mode`, `pop_mode`, `quit`, `frame_time`.
- `game_world`: `add_object(o, depth)`, `remove_object(o)`, `update()`, `render()`, `add_collision_pair(group, a, b)`, `handle_collisions()`, `clear()`.
- 객체 인터페이스: `update()`, `draw()`, `handle_event(e)`(플레이어만), `get_bb() -> (l, b, r, t)`, `handle_collision(group, other)`.

### 5.2 레이어 (depth)
`0 배경(패럴랙스) · 1 맵/발판/위험물/파괴물/문/스위치/안전지대/숨구멍/NPC/아이템/마법진 · 2 적·투사체 · 3 플레이어 · 4 이펙트·전경 · 5 UI`

### 5.3 좌표와 카메라
- pico2d는 **좌하단 원점, y 위쪽 증가**.
- **모든 객체의 위치와 `get_bb()`는 월드 좌표**(방 좌하단 = (0, 0)). 방 크기는 `size × (1280, 720)`.
- 그릴 때만 `camera.to_screen(x, y)`로 화면 좌표로 바꾼다. 디버그 hitbox(F1)도 마찬가지.
- 화면 밖(여유 100px) 객체는 그리지 않는다. update는 방 안의 모든 객체가 한다.
- HUD·메뉴는 화면 좌표로 그린다.

### 5.4 충돌
- AABB. 지형 충돌은 **X 이동 → X 해결 → Y 이동 → Y 해결**.
- 발판(one-way): 위에서 떨어질 때만 착지.
- 공격 hitbox는 몸 hitbox와 별개로 활성 시간 동안만 생성, 이번 공격에서 맞힌 대상 목록을 가진다.
- 공격 hitbox 충돌 대상: 적, 보스, 파괴물, 레버, 가시(아래 공격 포고용). 곡괭이로 투사체는 막지 못한다.
- 위험물은 몸 hitbox와 충돌하면 6.8 규칙. **숨 영역(안전지대·숨 소모 배율 영역·물)은 몸 hitbox 중심점으로 판정**한다.

### 5.5 히트스톱 (v2와 같음)
- `systems/hitstop.py`에 전역 타이머. 히트스톱 중에는 월드 update를 건너뛰고 이펙트·카메라만 갱신.
- 슬로모션은 `frame_time`에 배율을 곱해 월드에 전달. **숨 소모도 이 배율을 따른다** (히트스톱 중 숨은 줄지 않음).
- 겹치면 `남은 시간 = max(남은 시간, 새 요청)`.

### 5.6 영구 ID와 월드 상태
- 상태가 저장되는 객체(파괴물, 문, 레버, 아이템, 안전지대, 스위치, 실종 광부, 새김터, 정예, 보스)는 방 JSON에서 `id`를 가지며, 전역 ID는 `"<방id>:<객체id>"`.
- 상태는 `world_state`(13.6)에 저장. 방을 불러올 때 이미 부서진 벽·주운 아이템은 만들지 않는다.
- 일반 적은 저장하지 않는다. 정예·보스는 처치 기록을 저장한다.

### 6.4 이동 사양
- **즉시 가감속**: 방향키를 누르면 바로 `PLAYER_SPEED`, 떼면 바로 0. 공중 제어 100%.
- **점프 (누르는 동안 상승)**:
  1. Z를 누르면 `vy = JUMP_SPEED`.
  2. 누르고 있는 동안 `JUMP_HOLD_MAX`까지 `vy` 유지 (중력 무시).
  3. 그 뒤 중력 적용.
  4. `JUMP_HOLD_MIN`이 지난 뒤 Z를 떼면 `vy > 0`일 때 `vy *= JUMP_CUT`.
- **코요테 타임**, **점프 버퍼**, **최대 낙하 속도**.
- **강착지**: `HARD_LAND_FALL_TIME` 이상 떨어진 뒤 착지하면 `HARD_LAND_LOCK` 입력 잠금 + 큰 먼지. 포고·대시·디딤을 쓰면 체공 시간 리셋.
- **코너 보정**: 머리가 천장 모서리에 `CORNER_CORRECTION` 이내로 걸리면 옆으로 밀어 통과.
- **벽 매달리기**(버팀의 룬): 공중에서 벽 쪽 방향키 → WallSlide. 곡괭이를 벽에 박고 미끄러지는 모습 + 불꽃. Z로 벽점프 (`WALL_JUMP_LOCK` 동안 수평 입력 무시). 같은 벽 재매달림 가능. 대시·디딤 재충전.
- **굴착 대시**(굴착의 룬): 수평 `DASH_DIST`/`DASH_TIME`, 중력 무시, 공중 1회, 쿨 `DASH_COOLDOWN`. **무적 아님.** 무른 흙벽에 대시로 닿으면 흙벽을 파고 통과 (흙벽은 다시 메워지지 않음, 영구).
- **그림자 질풍**(그림자의 룬): C를 눌렀을 때 `SHADOW_DASH_COOLDOWN`이 차 있으면 발동. 같은 거리, **무적**, 그림자 장막 통과.
- **결정 디딤**(결정의 룬): 공중에서 Z → 발밑에 결정 발판이 잠깐 생겼다 부서지며 다시 도약. Lv3에서 2회.
- **돌파**(돌파의 룬): 바닥이나 벽에서 D를 누르면 `BREAK_CHARGE_TIME` 충전 → 떼면 `BREAK_SPEED` 직선 돌진. 벽에 닿거나 D를 다시 누르면 정지. 돌진 중 피격되면 정지.

### 6.5 곡괭이 공격
- X: **단타**. 쿨 `ATTACK_COOLDOWN`, hitbox 유지 `ATTACK_ACTIVE`. 옆 공격 모션 두 가지를 번갈아 재생 (판정은 같음).
- **방향**: 기본 = 바라보는 방향. ↑+X = 위. **공중에서만** ↓+X = 아래.
- **반동**: 옆 공격이 적·파괴물·레버에 맞으면 플레이어가 `ATTACK_RECOIL` 밀린다. 위 공격은 반동 없음.
- **포고**: 아래 공격이 적·가시·파괴물에 맞으면 `vy = POGO_SPEED`. 대시·디딤 재충전. 가시와 동시 접촉 시 **포고를 먼저** 처리.
- **곡괭이만 할 수 있는 것**: 균열벽(`CRACK_WALL_HITS`), 광맥벽(곡괭이 `ORE_VEIN_LEVEL` 이상, 희귀 광석), 광석 덩어리 캐기, 결정 숨주머니 깨기.
- **피해**: `PICKAXE_DAMAGE[곡괭이 레벨 - 1]`. 대장간에서 강화 (13.3). **[v3.1] 강화는 B3 처치 후(수정 숫돌)부터 가능하므로, R1~R3 구간은 곡괭이 Lv1 기준으로 적·보스 체력을 맞춘다.**
- **v2 대비 삭제**: 3연타, `COMBO_WINDOW`, lunge. **T21의 히트스톱·스파크·적 떨림·경직 코드는 그대로 쓴다.**

### 6.6 타격감
목표는 v2와 같다: **맞혔을 때와 헛스윙했을 때가 확실히 다르게 느껴질 것.**

| 요소 | 값 | 비고 |
|---|---|---|
| 히트스톱 | `HITSTOP_HIT` | 공격 1회당 1번 |
| 적 넉백 | `ENEMY_KNOCKBACK` | 보스·무거운 적 없음 |
| 플레이어 반동 | `ATTACK_RECOIL` | 옆 공격만 |
| 화면 흔들림 | 처치 타격만 `SHAKE_KILL` | |
| 타격 스파크 | `HIT_SPARK_COUNT` | 피해 없는 부위는 회색 |
| 적 몸 떨림 | `ENEMY_HIT_SHAKE` | 그리는 위치만 흔듦 |
| 적 경직 | `ENEMY_FLINCH_TIME` | `Idle`/`Chase`에서만 |

- **색 규칙(v2 유지)**: 맞은 적의 몸 색은 바꾸지 않는다. 흰색·빨간색 번쩍임은 **예고 전용**이다.
- 처치 타격이면 `HITSTOP_KILL`과 `HITSTOP_HIT` 중 큰 값 하나만.
- **플레이어 피격**: `HITSTOP_HURT` + `SHAKE_HURT` + 화면 가장자리 어둡게 번쩍 + `HURT_KNOCKBACK` + 무적 깜빡임. 체력 1칸이면 심장 박동 소리.

### 6.7 체력
- 칸 단위. 시작 `HP_START`, 최대 `HP_MAX`. 최대 체력은 **대장간 광부 갑옷 강화**로만 늘린다 (13.3).
- 회복 방법: ① 안전지대에 앉기(전부) ② **숨 고르기**: A를 `RUNE_HOLD_THRESHOLD` 이상 누르면 Mend 시작, `HEAL_TIME` 동안 이동 불가, 끝나면 숨 `HEAL_BREATH_COST`를 쓰고 1칸 회복. 계속 누르면 다음 칸. 숨이 모자라면 시작하지 않는다 (작은 '헉' 소리).

### 6.8 피격 · 환경 피해
- **접촉 피해** `CONTACT_DAMAGE`, **공격 피해**는 적 데이터의 `damage`. 패링 실패 경직 중이면 × `STUN_DAMAGE_MULT` 올림.
- **무적**: `INVINCIBLE_ON_HIT`.
- **환경 피해**(가시·산성·구덩이): `HAZARD_DAMAGE` → 페이드 → 마지막 안전 지점(`safe_points` 중 마지막으로 밟은 곳, 없으면 마지막으로 2초 이상 서 있던 바닥). **숨은 되돌리지 않는다** (안전 지점 복귀가 숨 낭비를 막는 수단이 되면 안 됨).
- **질식**: 7.3.
- 체력 0 → 사망 연출 1.5초 → 13.2.

## 7. 숨 시스템 [v3 핵심]

### 7.1 설정
- 유적은 봉인되어 공기가 없다. 숨을 쉴 수 있는 곳은 **안전지대**뿐이다: 지상 공기가 새어 드는 틈, 왕국이 룬으로 공기를 만들던 '숨방', 이끼가 공기를 내는 동굴 등.
- 안전지대 밖에서는 숨을 참고 움직인다. 숨 게이지가 시간에 따라 줄고, 0이 되면 질식한다.
- 숨을 늘리는 유일한 영구 수단은 **숨의 룬과 그 강화**다. 그래서 숨의 룬이 없으면 R2까지 닿을 수 없다.

### 7.2 숨 게이지 동작 (`systems/breath.py`)
- 최대치 `BREATH_CAPACITY[숨의 룬 레벨]` (+ 각인 보정).
- 매 프레임 `숨 -= BREATH_DRAIN × 배율 × frame_time`. 배율은 현재 위치의 숨 영역 중 **가장 큰 값**: 구역 기본 `REGIONS.air` → 방 안 `breath_zones`(포자·물 등).
- 안전지대 안: 소모 없음, `BREATH_REFILL_RATE`로 회복. 나선 직후 `BREATH_EXIT_GRACE` 동안 소모 유예.
- 소모가 멈추는 경우: 안전지대 안, 대화·메뉴·컷신·룬 획득 연출 중, 히트스톱 중, 광산(R0).
- 숨 쓰는 행동: 숨 고르기 `HEAL_BREATH_COST`, 룬 기술 `SKILL_BREATH_COST`. 숨이 모자라면 발동하지 않는다.
- 숨 얻는 방법:

| 방법 | 양 | 비고 |
|---|---|---|
| 안전지대 | 가득 | 초당 `BREATH_REFILL_RATE`로 차오름 |
| 숨구멍(`air_vent`) | `AIR_VENT_REFILL` | 벽 틈에서 바람이 새는 곳. 닿으면 회복, `AIR_VENT_COOLDOWN` 뒤 재사용 |
| 결정 숨주머니 (R3) | `CRYSTAL_POCKET_REFILL` | 곡괭이로 깨는 공기 결정. 영구 파괴 |
| 패링 성공 | `BREATH_PER_PARRY` | **[v3.2] 각인 「받아친 숨」을 장착했을 때만** (8.4 #7). 받아치는 순간 각인이 숨을 고르게 해 준다. 미장착이면 0 (연출도 없음). 「되받은 숨」을 함께 장착하면 2배 |
| 보스 그로기 | `BREATH_GROGGY_BURST` | 보스 몸의 공기 주머니가 터짐 (11.2) |
| 적 처치 | `BREATH_PER_KILL` | 기본 0 (T58에서 결정) |

### 7.3 숨 부족 · 질식
- `BREATH_LOW_RATIO` 아래: 숨소리가 가빠지고 화면 가장자리가 점점 어두워지며 HUD 게이지가 깜빡인다.
- 0: **질식**. `SUFFOCATE_INTERVAL`마다 체력 1칸 감소 (히트스톱·무적 연출 없이 짧은 기침 + 화면 어둡게 깜빡). 숨 고르기 불가. 안전지대나 숨구멍에 닿으면 즉시 멈춘다.
- 질식으로 체력이 0이 되면 사망 (13.2). 일반 피격 무적 시간은 질식 피해를 막지 않는다.

### 7.4 R1 → R2: 숨의 룬 게이트 (사용자 요구 반영)
- R1과 R2 사이에 **'숨막이 갱'**이 있다: 숨구멍·안전지대가 하나도 없는 긴 밀폐 통로.
- 숨의 룬이 없으면(레벨 0) **아무리 빨리 가도 통과할 수 없다.** 이것은 '어렵게'가 아니라 '불가능하게' 만든다 (7.6 검사).
- **[v3.2]** 「받아친 숨」은 숨의 룬과 함께 받으므로 숨의 룬 전에는 패링으로 숨을 얻을 수 없다. 따라서 숨막이 갱에 적을 두더라도 '패링으로 숨을 벌어 통과'하는 우회는 생기지 않는다.
- 통로 중간의 석판: "숨을 길게 잇는 룬 없이는 아무도 이 길을 건너지 못했다."
- 숨의 룬은 R1의 **숨은 새김터**에서 룬지기 오람에게 받는다. 숨은 새김터는 곡괭이로 깨는 숨은 벽 뒤에 있다.
- 받은 직후 오람이 '룬은 광석으로 더 깊이 새길 수 있다'고 알려주고, 첫 강화(Lv1→2)를 저렴하게 해 준다 → 강화 시스템을 바로 배운다.
- **[v3.2]** 같은 대화에서 오람이 숨의 룬에 첫 각인 「받아친 숨」을 새겨 준다 (숨의 룬 1번 홈에 장착된 상태). "받아칠 때 숨이 돌아올 거다. 각인은 숨방에 앉아 바꿔 새길 수 있다" — 각인 시스템도 여기서 처음 소개한다. 설명 카드에 '받아친 숨: 패링 성공 시 숨 회복'을 한 줄 적는다.

### 7.5 숨은 새김터를 반드시 찾게 하는 장치
숨겨져 있되, 플레이어가 막혀서 그만두지 않게 한다.
1. **바람 단서**: 숨은 벽 앞에서는 먼지가 벽 틈으로 빨려 들어간다 (그 뒤에 공기가 있다는 표시). 숨구멍과 같은 소리가 희미하게 난다.
2. **석판 단서**: R1 석판 2개가 "공기를 새기는 이가 회랑 깊은 곳 벽 너머에 있다"고 말한다.
3. **보름 힌트**: 숨막이 갱에서 숨이 떨어져 돌아온 횟수가 `HINT_FAIL_COUNT`에 닿으면, 보름이 "벽에서 바람 소리가 나는 곳을 봤다"며 대략적인 위치를 말해준다. 한 번 더 실패하면 지도에 물음표 표시.
4. **[v3.1]** 숨은 새김터는 **R1 허브(보름 캠프 안전지대)에서 한 방 거리**에 둔다. 숨은 벽은 허브 바로 옆 방에 있어, 플레이어가 허브를 오갈 때마다 바람 단서를 지나친다.

### 7.6 숨 예산 (정확한 수치는 T58에서 확정)
숨 수치는 **맵 구성, 플레이어 이동 속도, 보스 체력·속도**를 모두 봐야 정할 수 있으므로 후반부에 한 번에 확정한다. 그 전까지는 `# 임시` 값으로 개발하고, 방을 만들 때 아래 규칙만 지킨다.

**용어**
- **구간**: 숨이 회복되는 지점(안전지대·숨구멍) 사이의 경로.
- **최단 필요 숨**: 그 시점에 얻을 수 있는 **모든 능력**으로 최단 경로를 최고 속도로 갔을 때 쓰는 숨 (`이동 시간 × 배율`의 합).
- **일반 필요 숨**: 최단 필요 숨 × `BREATH_MARGIN` (적과 싸우고 헤매는 시간 포함).

**규칙**
1. **게이트 구간**(예: 숨막이 갱)은 `최단 필요 숨 > 요구 레벨 직전 용량`이어야 한다 → 그 레벨 없이는 불가능.
2. 모든 구간은 `일반 필요 숨 ≤ 그 구간에 올 때 예상 숨 레벨의 용량`이어야 한다 → 정상 진행이면 질식하지 않는다.
3. 보스전: `BOSS_FIGHT_TARGET × 아레나 배율 ≤ 용량 + 예상 패링 회복 + 그로기 회복` (원칙 15). **[v3.2] 「받아친 숨」 없이 싸울 수 있는 보스(B1)는 예상 패링 회복 = 0으로 계산한다.**
4. 숨 레벨을 올리면 이전에 못 가던 **선택 구간**(숨은 방·수집품)이 최소 2곳 열린다 → "강화하면 더 멀리 간다".
5. 능력을 새로 얻으면(특히 대시·디딤·돌파) 이전 게이트 구간의 최단 시간이 줄어든다. **게이트 구간은 '그 게이트를 지날 시점에 얻을 수 있는 모든 능력' 기준으로 검사**한다.

**도구** (`tools/breath_budget.py`, T58)
- 방 JSON의 안전지대·숨구멍·출구·숨 영역을 그래프로 만들고, 구간마다 최단 필요 숨을 계산한다 (방 안 이동 거리 / `PLAYER_SPEED` + 수직 이동 보정 + 가중치).
- 실제 플레이 측정값(디버그 HUD의 구간 타이머)을 `data/breath_budget.json`에 기록해 계산값과 비교한다.
- 규칙 1~3을 어기는 구간을 출력한다.

**T58 측정표 형식** (`data/breath_budget.json`)

| 구간 | 출발 → 도착 | 배율 | 최단(계산) | 실측 평균 | 요구 숨 Lv | 판정 |
|---|---|---|---|---|---|---|
| 예: 숨막이 갱 | R1_S2 → R2_S1 | normal | ? | ? | 1 | 게이트 |

## 8. 룬 · 각인 [v3]

### 8.1 룬의 원칙
- 룬은 **보스의 정체가 남긴 힘**이다. 보스가 살아온 방식(파고들기, 버티기, 결정, 부수기, 그림자)이 그대로 능력이 된다.
- 룬 하나가 **① 전투 동작 ② 탐험 동작 ③ 다음 구역의 진입 조건**을 동시에 바꾼다.
- 룬은 레벨이 있다. **룬지기에게 광석을 주고 강화**하면 새 동작이 붙고, 전에 못 가던 곳이 열린다.

### 8.2 룬 목록

| 룬 | 얻는 곳 | Lv1 | Lv2 | Lv3 (이상) | 여는 진입 조건 |
|---|---|---|---|---|---|
| 숨의 룬 | R1 숨은 새김터 (룬지기) | 숨 용량 증가 **+ [v3.2] 첫 각인 「받아친 숨」 지급** | 용량 ↑ | Lv3~5 용량 ↑ | **R2: 숨막이 갱** · R4 깊은 물 (Lv3) · R6 (Lv4) |
| 굴착의 룬 | B1 바위껍질 굴착충 | 대시 + 무른 흙벽 통과 | 낙반 (↓+A, 깨지는 바닥) | 단단한 흙벽 통과, 대시 거리 +30% | R2 내부 흙벽, R3 일부 바닥 |
| 버팀의 룬 | B2 이끼 수문장 | 벽 매달리기·벽점프 | 가시 덩굴벽에도 매달림 | 매달린 동안 숨 소모 절반 | **R3: 수직 갱** |

- 보스와 룬의 연결 이유:
  - **굴착충** → 땅을 파고 다니던 몸놀림 → 흙을 뚫는 대시
  - **이끼 수문장** → 수백 년 수문을 버틴 힘 → 벽에 곡괭이를 박고 버티기
  - **수정 대술사** → 공중에 결정을 세워 순간이동하던 술법 → 공중 결정 발판
  - **신전 골렘 거상** → 신전을 부수던 주먹의 돌진력 → 돌파
  - **쌍낫 군주** → 그림자 속을 지나던 사냥 기술 → 그림자 질풍
- 룬 기술(A 짧게)은 숨 `SKILL_BREATH_COST`를 쓴다. 적중 시 자세 +`POSTURE_PER_SKILL`. 시전 중 `Cast` 0.2초, 피격 시 취소.

### 8.3 룬 강화 (룬지기 오람, `carver_mode`)
- 숨은 새김터에서 오람에게 ↑로 말을 걸면 → 대화 → 강화 목록. ←→로 룬 선택, X로 강화.
- 비용 `RUNE_UPGRADE_COST` (광석 + 희귀 광석, `# 임시`). **보관 광석**으로만 지불한다 (13.2).
- 강화하면 8.5의 룬 획득 연출을 짧게(0.5초) 재생하고 설명 카드에 새 동작을 보여준다. 자동 저장.
- **[v3.1] 오람은 R1 숨은 새김터에서만 만난다.** 몸이 돌이 되어 움직일 수 없다는 설정이다. 다른 구역에 새김터는 없다.
- **[v3.1] 찾아가기 쉽게 하는 맵 구성** (12.1, 12.4):
  1. 새김터는 R1 허브(보름 캠프) 안전지대에서 한 방 거리, 이동 `CARVER_FROM_HUB_MAX`초 이하.
  2. 각 구역은 첫 안전지대 근처에서 **R1 허브로 바로 돌아오는 숏컷**(한쪽 문·엘리베이터·흙벽)을 연다. 숏컷을 연 뒤에는 그 구역 첫 안전지대 → 허브가 `SHORTCUT_TO_HUB_MAX_ROOMS`방 이하.
  3. 숏컷은 **먼 쪽(구역 안쪽)에서만 열린다**. 그래서 진입 게이트(숨막이 갱 등)를 우회하지 못한다.
  4. 새김터를 처음 찾으면 지도에 새김터 아이콘이 영구 표시되고, 각 구역 지도에서 허브 방향 숏컷이 화살표로 표시된다.
  5. 새 룬을 얻으면 rune_get 설명 카드 아래에 "룬지기에게 가면 더 깊이 새길 수 있다" 한 줄을 띄운다 (처음 3번만).
- 강화 우선순위를 플레이어가 고르게 한다: 숨을 먼저 올려 멀리 갈지, 굴착·버팀을 올려 숨은 길을 열지. 희귀 광석은 대장간(곡괭이·갑옷)과 경쟁한다.

### 8.5 룬 획득 연출 (`rune_get_mode`)
1. 룬지기에게 받거나, 보스가 남긴 룬 조각에 닿는다.
2. 히트스톱 0.1초 → 화면이 어두워짐 → 룬 문양이 플레이어에게 흡수 (0.8초) → 섬광 (구역색).
3. 설명 카드: 룬 이름, 키 아이콘, 한 줄 설명, **이 룬으로 열리는 곳 힌트 한 줄**. "X: 확인".
4. 복귀 후 **같은 방이나 바로 다음 방에 그 능력을 바로 써야 하는 짧은 구간**을 둔다.
- `world_state.runes`에 추가, 즉시 자동 저장.
- **[v3.1]** 반사 해금(10.4)도 이 모드를 재사용한다 (룬 문양 대신 갑각 방패 문양, 설명 카드 "S로 투사체를 받아치면 되돌려 보낸다").

## 9. 패링 시스템 (v2 6장 유지 + v3 변경)

### 9.1 적 공격의 단계 (v2와 같음)
1. **Telegraph**: 흰색 = 패링 가능, 빨간색 = 패링 불가(+'!'). 최소 `TELEGRAPH_MIN`.
2. **Windup** 3. **Active** (이 시점에 판정) 4. **Recover**.
- 적 몸이 아닌 곳에서 생기는 공격(마법진, 포자 구름, 낙석, 충격파)은 생기는 위치에 빨간 테두리·그림자로 예고하고, 시전하는 적도 빨간색으로 번쩍인다.

### 9.2 판정 (v2와 같음, **패링은** 처음부터 사용 가능)
- S 입력 시 `PARRY_WINDOW` 동안 `parry_active = True`.
- 적 공격 hitbox(또는 투사체)가 닿았을 때 `parry_active`이고 패링 가능 → **성공**, 그 외 → 피격.
- 아무것도 막지 못하면 **헛입력** → `ParryStun` `PARRY_FAIL_STUN`.

### 9.3 성공 시
- 히트스톱 `HITSTOP_PARRY` + `SHAKE_PARRY` + 흰 섬광 + 금속 충돌음.
- 근접: 적 `Stagger` `ENEMY_STAGGER_TIME`, 받는 피해 × `STAGGER_DAMAGE_MULT`.
- 투사체:
  - **[v3.1] 반사 해금 전**(`not player.can('reflect')`): 투사체가 그 자리에서 튕겨 사라진다(작은 파편 이펙트). 피해·자세 증가 없음.
  - 반사 해금 후: 방향 반전·소유자 플레이어·피해 × `REFLECT_DAMAGE_MULT` (v2 그대로). 반사탄이 보스·정예에 맞으면 자세 +`POSTURE_REFLECT`.
- 보스·정예: 자세 +`POSTURE_PARRY` (근접 패링, 반사 해금 전 투사체 패링 포함하지 않음).
- `PARRY_COOLDOWN` 즉시 0.
- **[v3.2] 숨 +`BREATH_PER_PARRY` — 각인 「받아친 숨」 장착 시에만** (숨 게이지가 짧게 파랗게 차오르는 연출도 이때만). 패링 처리 코드는 `breath.add(engravings.parry_breath_gain())`를 **한 번만** 호출한다 (8.4).
- 각인 훅 `engravings.on_parry_success(player, target)`.

### 9.4 자세 게이지 (보스·정예)
- `posture` 0 ~ `POSTURE_MAX`. 패링 +`POSTURE_PARRY`, 곡괭이 +`POSTURE_PER_HIT`, 룬 기술 +`POSTURE_PER_SKILL`, 반사탄 +`POSTURE_REFLECT`.
- 가득 차면 **그로기** `GROGGY_TIME` + 슬로모션 `GROGGY_SLOWMO`, 받는 피해 × `GROGGY_DAMAGE_MULT`. **[v3] 그로기 시작 시 보스 몸의 공기 주머니가 터져 숨 +`BREATH_GROGGY_BURST`.** 끝나면 0.
- 줄어들지 않는다. 그로기 중에는 오르지 않는다. 페이즈 전환 중에는 그로기가 시작되지 않는다.

### 9.5 패링을 쓰게 되는 흐름
1. **[v3.2] 패링은 해금·학습 단계 없이 처음부터 쓸 수 있다.** R1 두 번째 안전지대 옆의 '연습 석상'은 **진행을 막지 않는 선택 요소**다: 3초마다 흰 내려치기 (피해 없음), 3번 성공하면 석상이 부서지며 광석 소량. 「받아친 숨」을 얻기 전이므로 숨은 차지 않는다.
2. R1 갑각 전사 첫 등장: 흰 베기 2연타.
3. B1 굴착충: 흰 돌진을 패링하면 크게 유리.
4. R2 쇠뇌 회랑(흰 화살을 패링으로 **막아 없애기**) → 반격의 시련(정예 갑각 대장) → **[v3.1] 처치 시 반사 해금** → 해금 직후 같은 방의 쇠뇌로 반사 연습(수정 스위치 대신 쇠뇌 과녁) → B2.

## 10. 적 [v3]

### 10.1 공통 AI (`enemy_base.py`)
`Idle → Chase → Telegraph → Windup → Active → Recover → (Chase)`
- 패링당하면 `Stagger`. HP 0 → `Dead` (파티클 + `HITSTOP_KILL` + 광석 드롭).
- `Idle`/`Chase`에서 맞으면 `Flinch` → `Chase`.
- 공격은 데이터로 정의: `Attack(name, parryable, telegraph, windup, active, recover, damage, hitbox)`.
- v2의 루트 난이도 배율은 없앤다. 적마다 고정 수치이고 뒤 구역일수록 센 적.
- 적은 자기 방 밖으로 나가지 않는다. **안전지대 영역에 들어오지 않는다** (경계에서 돌아섬).
- 감지: `aggro_dist` 안 + 시야(같은 높이 ±200px, 벽 너머 아님). Idle에서 작은 동작.
- 광석: 처치 시 `ore` 만큼 1~5짜리 조각으로 위로 튀게 뿌린다.

- **갱도 벌레**: 일정 속도 이동, 앞이 벽이거나 발판 끝이면 돌아선다. 공격 상태 없음.

- **덩굴 매복충**: 숨음 상태에서 hitbox 없음, 흙 무더기로 위치 힌트. `ambush_dist` 안이면 빨간 예고 → 물기 → 이후 근접 적.
- **독 거머리**: 방 JSON `water` 영역 안에서만 이동. 수면 위 `trigger_dist` 안이면 흰 예고 → 포물선 도약. 물 밖에 떨어지면 1초 뒤 사망.
- **유적 골렘**: 넉백·Flinch 없음. 충격파는 바닥을 따라 양쪽으로 가는 낮은 투사체 (점프, 패링 불가).

## 11. 보스 설계 [v3]

### 11.1 보스 설계 원칙 (할로우 나이트 참고 14 + 숨 1)
모든 보스(정예 포함)는 이 원칙을 지킨다.

1. **모든 공격은 읽힌다.** 공격마다 고유한 예비 자세 + 고유한 소리. 예고 0.4~0.8초 기본, `TELEGRAPH_MIN` 아래 금지. 자세에 흰/빨강 색을 더한다.
2. **패턴은 적게, 명확하게.** 기본 3~5개. 어려움은 속도·연결·조합에서.
3. **반격의 틈을 보장한다.** 모든 패턴 끝에 후딜 최소 0.6초.
4. **피해는 공정하다.** 대부분 1칸, 강공격만 2칸. 무적 중 다단 히트 없음. 화면 밖 공격은 소리로 먼저.
5. **실패의 이유가 보인다.** 무엇에 맞았는지 알 수 있게. 무작위 판정 금지.
6. **페이즈는 같은 보스의 심화다.** 연출과 함께 속도 상승 또는 패턴 1~2개 추가. 새 패턴은 처음엔 가장 느린 형태로.
7. **기절로 리듬을 끊는다.** 자세 게이지(9.4), 패링이 앞당긴다.
8. **보스는 직전에 얻은 능력의 졸업 시험이다.** 없이도 깰 수는 있지만 쓰면 확실히 쉽다.
9. **아레나는 단순하고 의도적이다.** 평지 + 발판 최대 2개, 기믹은 하나만.
10. **재도전은 빠르게.** 안전지대 → 보스방 `BOSS_RUNBACK_MAX`초 이하. 첫 만남만 풀 등장.
11. **보스에게는 정체성이 있다.** 이름 + 칭호 카드, 전용 BGM, 고유 실루엣. **그 정체성이 보상 룬이 된다** (8.2).
12. **체력바 대신 몸으로 알린다.** `BOSS_HP_BAR = False`, 66%·33%·페이즈에서 외형 변화.
13. **무작위는 상황으로 제한한다.** 거리 조건 + 가중치 + 같은 패턴 `BOSS_MAX_REPEAT`회 초과 금지 + 쿨다운.
14. **페이크는 아껴 쓴다.** 마지막 페이즈에서만, 한 순환 최대 1회. 다음 공격은 반드시 흰색.
15. **[v3] 숨 예산 안에서 끝난다.** 보스 아레나는 밀폐 공간이다. `BOSS_FIGHT_TARGET`(능숙한 플레이 기준 전투 시간)이 그 시점 예상 숨 용량 + 패링·그로기 회복 안에 들어와야 한다. 숨이 모자라 질 수는 있어도, 숨 때문에 **이길 방법이 없으면 안 된다.** 패링·그로기가 숨을 돌려주므로 '받아치며 싸우는 플레이'가 숨 문제를 푼다. **[v3.2] 단, 「받아친 숨」 전에는 패링이 숨을 주지 않으므로 그 시점 보스(B1)는 용량 + 그로기 회복만으로 계산한다.** 보스 체력·속도를 바꾸면 이 원칙을 다시 확인한다 (T58).

### 11.2 보스 공통 구현 (`bosses/boss_base.py`)
v2 보스 3체를 이 구조로 옮긴다 (T45).

- **상태**: `Dormant` → `Intro` → `Fight(phase n)` → `PhaseTransition` → `Groggy` → `Dying` → `Dead`
- **아레나 잠금**: 트리거에 들어가면 출구에 돌문 (`gate.py`, 아레나 문). 플레이어 사망 또는 보스 처치 시 열림.
- **숨**: 아레나는 밀폐. 등장 연출(Intro) 동안은 숨이 줄지 않는다. 바로 앞 방은 안전지대 (원칙 10, 15).
- **등장**: 첫 만남은 연출 + 타이틀 카드(`BOSS_INTRO_CARD_TIME`), 입력 잠금. 재도전은 `BOSS_INTRO_SHORT`. 첫 만남 여부 `world_state.bosses_met`.
- **페이즈 전환**: `phase_hp` 아래로 내려가면 `PHASE_TRANSITION_TIME` 무적 + 포효 + 흔들림 + 외형 변경 + 패턴표 교체 + 화면의 모든 적 투사체 제거.
- **패턴 데이터**: 순서 있는 동작 목록. 예: `[move_to('far'), attack('charge'), wait(1.0)]`.
- **패턴 선택**: 가중치 × 거리 조건, 직전 반복·쿨다운 제외, 패턴 사이 `BOSS_IDLE_GAP`.
- **피격**: 경직·넉백 없음. 떨림·스파크만. 자세 +.
- **외형 단계**: `damage_stage` 0/1/2를 체력 66%·33%에서 올린다. 도형 단계에서는 균열 선 + 색 한 단계 어둡게.
- **그로기**: 쓰러지는 모션, 약점 노출, **공기 주머니 터짐 → 숨 회복**, `GROGGY_TIME` 후 일어나며 0.3초 무적.
- **처치**: `BOSS_DEATH_SLOWMO` + 섬광 + 투사체·소환물 제거 → 1.5초 뒤 쓰러짐 → 룬 조각·광석 드롭 → 아레나 문 열림 → **보스가 품고 있던 공기가 풀려 아레나가 잠시 안전지대가 됨(숨 회복)** → BGM 페이드. `world_state.bosses_defeated`, 자동 저장.

### 12.3 기본 진행 순서 (critical path)
1. R0 도입부 → R1 추락 → 숨 게이지 등장
2. R1 탐험 → B1 → **굴착의 룬** (순서 자유) / 숨은 새김터 → **숨의 룬** + 첫 각인 「받아친 숨」 (**이때부터 패링이 숨을 돌려줌**) + 첫 강화
3. 숨막이 갱 통과 → R2 → 쇠뇌 회랑 → 반격의 시련 → **반사 해금** → B2 → **버팀의 룬**
4. R1 서쪽 수직 갱 → R3 → B3 → **결정의 룬** + 핵 1 + **수정 숫돌 → R1 대장간에서 곡괭이 강화 시작**
5. R3 높은 턱 → R4 → (숨 Lv3로 깊은 물) → 정예 신전 골렘 → B4 → **돌파의 룬** + 핵 2
6. 긴 구덩이 → R5 → B5 → **그림자의 룬** + 핵 3
7. 숨 Lv4 확인 → R1 최하층 봉인문 → R6 → B6 → 엔딩
- 각 룬·룬 강화 뒤 **이전 구역의 '보였지만 못 갔던 곳' 최소 2곳**이 새로 열려야 한다.
- **[v3.1]** 곡괭이 Lv3부터 열리는 광맥벽은 R1~R3에도 미리 보여두어, 곡괭이 강화 뒤 되돌아갈 이유를 만든다.

### 12.4 방 설계 규칙
- **보여주고 나중에 연다**: 능력·숨 게이트는 처음 지나칠 때 눈에 띄게 보여준다 (숨막이 갱 입구에 경고 석판, 흙벽 너머로 보이는 광맥 등).
- **얻으면 바로 쓴다**: 룬 획득·강화 직후 그 능력이 필요한 구간.
- **숨의 리듬**: 안전지대 → (긴장: 숨이 줄어듦) → 숨구멍(작은 안도) → 다시 긴장 → 안전지대. 숨구멍은 **갈림길이나 어려운 구간 직후**에 둔다.
- **숨 게이트는 정직하게**: 숨이 모자라 못 가는 길은 입구에서 '이 길은 길다'를 보여준다 (멀리 이어지는 통로, 경고 석판). 함정처럼 숨기지 않는다.
- **숏컷**: 안전지대에서 멀어지는 길마다 돌아오는 숏컷 (한쪽 문, 레버, 흙벽, 엘리베이터). 구역당 2~3개. 숏컷은 숨 예산을 줄이는 수단이기도 하다. **[v3.1] 그중 1개는 반드시 R1 허브행(8.3)이고, 먼 쪽에서만 열린다.**
- **[v3.1] 새김터 동선**: R1 허브 안전지대 → 새김터는 1방, `CARVER_FROM_HUB_MAX`초 이하. 길에 적·가시를 두지 않는다. 대장간도 허브에서 2방 이내.
- **숨은 벽**: 균열 무늬·바람 단서. 구역당 3~5개, 뒤에는 반드시 보상.
- **크기**: 1×1 ~ 3×2 화면. 출구는 방 가장자리.
- **출구 폭**: 옆 최소 120px, 위·아래 최소 160px. 위 출구는 `EXIT_UP_BOOST` + 착지 발판.
- **안전지대 간격**: 일반 진행 2~4방. 보스방 바로 앞 방은 반드시 안전지대.
- **가시 구간**: `safe_points`를 촘촘히.

## 13. 진행 시스템 [v3]

### 13.1 안전지대 (`safe_zone.py`)
- 공기가 있는 영역(`safe_zones`) + 그 안의 앉는 자리(`seat`). 시각적으로는 바람이 드나드는 틈, 초록빛 이끼, 왕국의 숨방(룬 문양이 빛나는 작은 방). **흰색·빨간색은 쓰지 않는다.**
- **영역 안에 들어오기만 해도**: 숨 회복, 숨 소모 정지, **소지 광석 자동 보관** (13.2), 적이 들어오지 않음.
- 처음 들어오면 공기가 들이차는 소리 + 숨 게이지가 크게 차오르는 연출.
- **↑로 앉으면**: 체력 전부 회복 · 자동 저장 · 부활 지점 갱신 · 일반 적 리스폰 · X로 `engrave_mode`(각인).
- ←, →, Z로 일어남.

### 13.2 광석 · 사망
- **소지 광석**: 적 처치, 광석 덩어리, 숨은 벽 뒤 무더기, 보스. `ORE_PICKUP_RADIUS` 안에서 자동 흡수.
- **보관 광석**: 안전지대 영역에 들어가는 순간 소지 광석이 전부 보관 광석으로 옮겨진다 (HUD 숫자가 이동하는 연출 + 짤랑 소리).
- **지불은 보관 광석으로만** (상점·대장간·룬지기는 모두 R1 허브 안전지대나 그 옆에 있다).
- **사망**: 1.5초 연출 → 암전 → 마지막으로 앉은 안전지대에서 부활 (체력 전부, 숨 가득). **소지 광석의 `DEATH_ORE_LOSS` 비율을 잃는다** (회수 불가). 보관 광석·희귀 광석은 잃지 않는다.
- 핵심 고민: "숨이 남았을 때 더 캘까, 지금 돌아가서 보관할까."
- v2의 결과(게임오버) 화면은 쓰지 않는다.

### 13.3 상점 · 대장간
- **보름 상점** (`config.SHOP`): ↑로 말 걸기 → 대화 → 목록 (←→ 선택, X 구매). 판매 조건이 있는 상품은 충족 전 목록에 없다.
- **실종 광부 보상** (`config.MINER_REWARDS`): 구출 2·4·6·8명일 때 보름에게 받는다.
- **대장간 하르**:
  - 광부 갑옷 Lv2~5 (`FORGE_ARMOR_COST`). 최대 체력 +1칸씩 (6~9칸). 처음부터 가능.
  - 곡괭이 Lv2~5 (`FORGE_PICKAXE_COST`). 피해 증가 + 곡괭이 각인 홈 증가. 색이 바뀐다. **[v3.1] `FORGE_PICKAXE_UNLOCK_FLAG`(B3 수정 숫돌)가 없으면 목록에 나오지 않고, 하르가 "결정만큼 단단한 숫돌이 있어야 이 날을 벼릴 수 있어" 한 줄만 말한다.** 숫돌을 처음 가져가면 짧은 대사 후 Lv2 강화가 바로 열린다.
- **룬지기 오람**: 8.3.

### 13.4 지도 (`map_mode`)
- Tab을 누르고 있는 동안 표시 (월드 일시정지, 숨도 정지).
- 방문한 방은 즉시 기록. 지도석을 얻으면 그 구역의 미방문 방도 회색 윤곽.
- 방마다 `map_cell`·`size`로 사각형, 출구 위치에 작은 틈, 구역색.
- **숨 정보**: 안전지대(큰 원), 숨구멍(작은 원), 숨 소모가 큰 방(물결·점 무늬)을 표시한다.
- 아이콘: 보름 캠프, 대장간, 새김터(**[v3.1] 찾은 뒤 영구 표시, 1곳**), 허브행 숏컷(연 뒤 화살표), 보스(처치 전·후), 현재 위치(**'광부의 나침반' 장착 시에만**).
- ←→↑↓로 스크롤.

### 13.5 디버그 숨 측정 (T37부터)

## 16. 알려진 함정

**v2에서 이어짐**
- pico2d 키 이벤트: 누름 `SDL_KEYDOWN`, 뗌 `SDL_KEYUP`. 좌우 동시 입력은 누름 상태를 따로 저장.
- 첫 프레임 `frame_time`은 최대 0.05초로 제한.
- 히트스톱 중에도 이벤트는 입력 버퍼에 저장.
- 순회 중 `remove_object` 금지. 모았다가 update 끝에 제거.
- 이미지 경로는 `os.path.join(os.path.dirname(__file__), ...)`.
- 맞은 적의 몸을 흰색·빨간색으로 칠하지 않는다.
- 히트스톱은 공격 1회당 1번, 겹치면 max.
- 방 전환 시 투사체·마법진·이펙트·소환물 정리.
- 순간이동 목적지는 방 안, 벽 밖, 바닥 위로 보정.

**[v3] 새로 생기는 것**
- **좌표 혼동**: 충돌·위치는 월드 좌표, 그리기만 화면 좌표. 디버그 hitbox도 변환.
- **출구 왕복**: `EXIT_SPAWN_INSET` + `TRANSITION_LOCK`.
- **아래 출구 낙하**: 검증 스크립트에서 도착 지점 아래 발판 검사.
- **누르는 동안 점프 + 히트스톱**: 히트스톱 중 `JUMP_HOLD_MAX` 타이머도 멈춘다.
- **A 키 길게/짧게**: 짧게는 '뗄 때' 판정.
- **숨 소모와 시간 배율**: 숨은 월드 `frame_time`(슬로모션·히트스톱 반영)으로 줄인다. 메뉴·대화·지도·룬 연출·방 전환 페이드 중에는 0. 빼먹으면 지도를 보는 동안 질식한다.
- **숨 영역 겹침**: 여러 배율 영역이 겹치면 **최댓값 하나만**. 곱하지 않는다. 안전지대가 겹치면 안전지대가 이긴다.
- **방 전환과 숨**: 방이 바뀌어도 숨은 이어진다 (방 로드 때 초기화하지 않는다). 안전지대 판정은 방 로드 직후 첫 프레임에 바로 한다.
- **숨 게이트 우회**: 나중에 얻는 대시·디딤·돌파로 게이트 구간 시간이 줄어 숨의 룬 없이 통과될 수 있다. 7.6 규칙 5대로 '그 시점에 얻을 수 있는 능력' 기준으로 검사한다. 숨의 룬보다 먼저 얻을 수 있는 굴착 대시는 반드시 포함해서 잰다.
- **질식 + 무적**: 질식 피해는 피격 무적을 무시하지만 히트스톱·넉백을 주지 않는다. 피격 무적 중 질식 피해로 무적이 갱신되지 않게 한다.
- **광석 보관 타이밍**: 안전지대 진입 순간 보관 → 그 직후 같은 프레임에 사망해도 보관된 광석은 안전.
- **각인 스탯 누적**: 매번 기본값에서 다시 계산. 룬 레벨 효과도 같은 방식.
- **영구 ID 중복**: 방 JSON 복사 시 id 겹침 → 검증 스크립트.
- **보스 재도전 초기화**: 보스 체력·자세·페이즈·소환물·아레나 기믹(B6 지하수 높이) 초기화. 플레이어 숨은 안전지대에서 가득 찬 상태로 다시 시작.
- **세이브 시점**: 항상 안전지대 기준. 페이드 중 저장 금지. 소지 광석·현재 숨은 저장하지 않는다.
- **pico2d 폰트**: 한글 TTF 필요. 크기 2~3개만 미리 만들어 재사용.
- **Tiled y축**: `y_pico = 방높이 - (y_tiled + h)`.
- **큰 방 성능**: 플레이어 주변 발판만 충돌 검사.
- **룬 확인 분산**: `player.can()`, `player.rune_lv()` 하나로.

**[v3.1] 새로 생기는 것**
- **패링 숨 조건 누락 [v3.2]**: 패링 숨 회복은 `engravings.parry_breath_gain()` 한 곳에서만 계산하고, 패링 처리에서 한 번만 더한다. 각인 훅이나 `breath.py`에 따로 넣지 않는다 (두 번 더해지거나 2배가 먼저 곱해지는 버그 방지).
- **각인 모듈 시점 [v3.2]**: `engravings.py`는 T37에서 껍데기로 생기고 T44에서 채워진다. T44에서 파일을 새로 만들어 덮어쓰지 말고 껍데기의 `is_set`·`parry_breath_gain`을 유지한다.
- **반사 잠금 누락**: 투사체 반전 코드는 `player.can('reflect')` 확인 뒤에만 실행한다. v2 반사 코드를 그대로 두면 처음부터 반사된다. 반사 해금 전에는 자세 증가·반사 통계(`reflects`)도 올리지 않는다.
- **숏컷이 게이트를 우회**: 허브행 숏컷은 반드시 구역 쪽에서만 열리는 한쪽 문이어야 한다. 양방향 문이면 숨막이 갱 등 게이트를 건너뛸 수 있다.
- **곡괭이 레벨 가정**: R1~R3의 적·보스·광석 덩어리 수치는 곡괭이 Lv1 기준. `PICKAXE_DAMAGE[1]` 이상을 가정한 배치를 하지 않는다.
