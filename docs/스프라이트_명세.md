# 스프라이트 명세 (T19)

> AI 이미지 생성 요청용 명세. 여기 적힌 **경로 · 셀 크기 · 프레임 수**대로 만들면 코드가 그대로 읽는다.
> 파일이 없으면 지금처럼 도형으로 그리므로, 일부만 먼저 넣어도 된다.

## 1. 공통 규칙

| 항목 | 규칙 |
|---|---|
| 형식 | PNG, **투명 배경**(알파 채널). 배경색 칠하지 않기 |
| 시트 배치 | 한 애니메이션 = 한 파일. 프레임을 **왼쪽 → 오른쪽 가로 한 줄**로 붙인다 (여백·구분선 없음) |
| 시트 크기 | `가로 = 셀 너비 × 프레임 수`, `세로 = 셀 높이` (예: 128×128 셀 6프레임 → 768×128) |
| 바라보는 방향 | **오른쪽**. 왼쪽은 코드에서 좌우 반전 |
| 기준점 | 캐릭터 **발바닥이 셀 맨 아래 가운데**에 닿게. 모든 프레임에서 발 위치가 같아야 흔들리지 않는다 |
| 몸 크기 | 셀 안에서 몸통이 표의 "몸 hitbox" 크기 정도. 남는 공간은 무기·이펙트용 |
| 스타일 | 모든 파일을 **같은 화풍**으로: 2D 픽셀아트, 측면 시점(사이드뷰), 외곽선 1px 어둡게 |
| 넣지 말 것 | 예고 번쩍임(흰/빨강), ‘!’ 아이콘, 피격 깜빡임, 그림자, 글자. **코드가 덧그린다** |

> 크기가 조금 어긋나게 나와도 괜찮다. 폴더에 넣어 주면 셀 크기에 맞게 자르고 늘리는 스크립트를 따로 만든다.

폴더 구조:
```
assets/
└─ images/
   ├─ player/      ├─ melee/      ├─ archer/    ├─ flyer/
   ├─ greatsword/  ├─ twinblade/  ├─ projectile/
   ├─ map/         └─ ui/
```

## 2. 플레이어 — `assets/images/player/` · 셀 128×128 · 몸 hitbox 40×64

검을 든 젊은 검사. 밝은 계열 옷(어두운 배경 30,30,40 위에서 잘 보이게).

> **실제 적용된 파일은 아래 표와 다르다.** 원본은 **512×512 칸을 2줄 격자**(왼→오, 위→아래)로 배치했고 프레임 수도 다르다.
> 코드는 `config.PLAYER_SPRITE_*`, `config.PLAYER_ANIM_FRAMES`(애니메이션별 사용할 칸 번호)로 읽는다.
>
> | 파일 | 칸 수 (가로×세로) | 사용 칸 |
> |---|---|---|
> | idle, attack1~3, parry, parry_stun, hit, jump | 4 (2×2) | 전부. jump만 0(상승)·2(낙하) |
> | run | 6 (3×2) | 전부 |
> | dash, dead | 8 (4×2) | 전부 |

| 파일 | 프레임 | 내용 |
|---|---|---|
| `idle.png` | 4 | 제자리 숨쉬기 |
| `run.png` | 6 | 달리기 한 사이클 |
| `jump.png` | 2 | 0: 상승, 1: 낙하 |
| `attack1.png` | 4 | 1타 가로 베기 |
| `attack2.png` | 4 | 2타 역방향 베기 |
| `attack3.png` | 5 | 3타 강한 내려베기/찌르기 (가장 크게) |
| `parry.png` | 3 | 검을 세워 막는 자세 |
| `parry_stun.png` | 3 | 헛패링 후 휘청 |
| `dash.png` | 3 | 몸을 낮춘 빠른 돌진 |
| `hit.png` | 2 | 맞고 뒤로 젖혀짐 |
| `dead.png` | 6 | 쓰러짐 (마지막 프레임은 누운 상태로 유지) |

## 8. 우선순위

1. **필수**: 플레이어 전부, 근거리 병사, 궁수, 플라잉 몹, `arrow.png`, 대검 기사
2. **권장**: 쌍검 기사, 맵 타일·문·배경
3. **선택**: 검기 2종, UI

## 9. AI 요청 프롬프트 예시

```
2D pixel art sprite sheet, side view, character facing right,
transparent background, no shadow, no text.
A young swordsman, light-colored clothes, dark 1px outline.
Animation: "run", 6 frames in a single horizontal row,
each frame exactly 128x128 px, total image 768x128 px.
Feet touch the bottom center of every frame, same position in all frames.
Consistent character design across all frames.
```

같은 캐릭터의 다른 애니메이션을 요청할 때는 **먼저 만든 `idle.png`를 참고 이미지로 함께 주고** "same character as the reference"를 붙이면 화풍이 덜 흔들린다.
