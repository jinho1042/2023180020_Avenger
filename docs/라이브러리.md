# 사용 라이브러리

> 기준일: 2026-11-02 · 개발 환경에서 `pip show`로 확인한 버전

## 1. 실행 환경

| 항목 | 버전 | 비고 |
|---|---|---|
| Python | 3.13.15 | 3.x면 동작. 표준 라이브러리 외 의존은 아래 3개뿐 |
| OS | Windows 11 | 폰트 경로(`C:/Windows/Fonts/malgun.ttf`)가 Windows 기준 |

## 2. 외부 라이브러리

| 패키지 | 버전 | 역할 | 직접 import 여부 |
|---|---|---|---|
| `pico2d` | 1.5.1 | 2DGP 수업용 2D 게임 래퍼. 창·이벤트·도형/이미지/폰트 그리기 | O |
| `PySDL2` | 0.9.17 | SDL2의 Python 바인딩. pico2d가 내부에서 사용 | O (일부) |
| `pysdl2-dll` | 2.32.10 | SDL2 / SDL2_image / SDL2_ttf / SDL2_mixer DLL 번들 | X (pico2d 의존성으로 설치) |

### 설치

```
pip install pico2d
```

`pico2d`를 설치하면 `PySDL2`, `pysdl2-dll`이 함께 설치된다.

## 3. 라이브러리별 사용 위치

### 3.1 pico2d

| 함수 / 상수 | 사용 위치 | 용도 |
|---|---|---|
| `open_canvas`, `close_canvas` | `main.py` | 1280×720 창 생성·종료 |
| `get_time` | `game_framework.py` | `frame_time` 계산 |
| `get_events`, `SDL_QUIT`, `SDL_KEYDOWN`, `SDL_KEYUP`, `SDLK_*` | `modes/*.py`, `objects/player.py` | 키 입력 처리 |
| `clear_canvas`, `update_canvas` | `modes/*.py` | 프레임 그리기 시작·화면 반영 |
| `draw_rectangle(l, b, r, t, R, G, B, A, filled)` | `objects/*.py`, `modes/play_mode.py` | 에셋 대체 도형, 디버그 hitbox |
| `load_font` | `modes/title_mode.py` | 타이틀 텍스트 (폰트 없으면 생략) |
| `clamp` | `objects/player.py`, `objects/enemy_base.py` | 화면 밖 이탈 방지 |
| `load_wav`, `load_music` | `systems/sound.py` | 효과음·배경음 (파일·오디오 장치 없으면 생략) |
| `pico2d.pico2d.renderer` | `systems/camera.py`, `objects/effect.py` | SDL 렌더러 직접 접근 (아래 3.2) |

> pico2d는 **좌하단 원점, y 위쪽 증가** 좌표계를 쓴다. 게임 내 모든 좌표가 이 기준이다.

### 3.2 PySDL2 (직접 호출)

pico2d가 제공하지 않는 기능 세 가지만 SDL을 직접 호출한다. 둘 다 `open_canvas` 이후 생기는 `pico2d.pico2d.renderer`를 사용하므로 **모듈 import 시점이 아니라 호출 시점에** 접근한다.

| 함수 | 사용 위치 | 용도 |
|---|---|---|
| `SDL_RenderSetViewport`, `SDL_Rect` | `systems/camera.py` | 화면 흔들림. 월드를 그리는 동안 viewport를 옮겨 모든 그리기에 오프셋 적용 |
| `SDL_SetRenderDrawBlendMode`, `SDL_BLENDMODE_BLEND` | `objects/effect.py` | 반투명 섬광·테두리 플래시 (알파 블렌딩) |
| `SDL_SetRenderDrawColor`, `SDL_RenderDrawLine` | `objects/effect.py` | 패링·처치·그로기 빛줄기 (pico2d에 선 그리기가 없음) |

## 4. 표준 라이브러리

| 모듈 | 사용 위치 | 용도 |
|---|---|---|
| `json` | `systems/room.py` | 방 템플릿(`data/rooms/*.json`) 로드 |
| `os` | `systems/room.py`, `modes/title_mode.py` | 실행 위치와 무관한 경로 조립, 폰트 존재 확인 |
| `random` | `systems/camera.py`, `objects/effect.py` | 흔들림 오프셋, 파티클 방향·속도 |
| `wave`, `struct`, `math` | `tools/gen_sounds.py` | 효과음 합성 (게임 실행에는 쓰지 않음) |
| `math` | `objects/effect.py` | 파티클 방향 벡터 (`cos`, `sin`) |

## 5. 앞으로 쓸 예정인 기능 (pico2d 범위 내)

| 기능 | pico2d API | 해당 작업 |
|---|---|---|
| 스프라이트 | `load_image`, `Image.clip_draw`, `Image.composite_draw` | T19 |
| 효과음·배경음 | `load_wav`, `load_music`, `set_volume`, `play`, `repeat_play` | T19 |

추가 외부 라이브러리는 도입하지 않는 것을 원칙으로 한다.
