# 맵 디테일 — 전투방 지형 가이드

> **무엇**: 전투방의 발판·지형·적 배치를 구역 특징에 맞게 다시 짜고, 숨의 룬 새김터를 숨기고, 구역마다 1~2개의 **잠금 전투방**(9장)을 두기 위한 작업 기준과 방별 수정 목록.
> **누가 쓰나**: 15.1의 **T66**(맵 디테일 반영)을 하는 작업 세션. T66은 T58(숨 예산 확정) **바로 앞**이다. T58은 방을 지나가는 시간을 재서 숨 수치를 확정하므로, 지형·적을 먼저 끝내야 다시 재지 않는다.
> **우선순위**: 명세(`개발문서v3.5.md`)와 부딪히면 명세가 이긴다. 이 문서는 명세 12.4(방 설계 규칙)·10.5(적 배치 규칙)·7.5(숨은 새김터)를 지형 쪽으로 구체화한 것이다.
> **기준 데이터**: 2026-11-18 `data/rooms/`. 좌표·동작 수치는 같은 날 `config.py`와 `objects/` 코드에서 확인했다.

## 0. 왜 필요한가 (현재 상태 진단)

보스방·게이트방을 뺀 전투방 29개의 발판을 그려 비교한 결과:

1. **가로방 절반이 같은 틀**이다 — "평평한 바닥 + 200px 안팎 통과 발판 2~3개 + 낮은 박스 1개".
   R1_02, R1_07, R2_02, R3_02, R3_06, R4_03, R5_02, R5_06, R5_10, R6_02, R6_03.
2. **수직방 5개가 같은 사다리**다 — 좌우로 번갈아 놓인 통과 발판을 타고 오르내린다.
   R1_06, R3_03, R4_06, R5_03, R5_07.
3. **같은 묶음을 복사한 흔적**이 있다 — "왼쪽 위 선반(x 40, y 440, 폭 400~500) + 그 오른쪽 균열벽 + 통과 발판 계단 2개(≈600,300 / ≈588,464) + 선반 위 광석 덩어리".
   R1_07, R1_08, R2_02, R2_06, R2_11.
4. **적이 거의 바닥에만**, 방 하나(2화면)에 1~2마리다. 명세 10.5는 "한 화면에 적 2~4", "쉬운 적을 어려운 지형 위에"를 요구한다.
5. **숨의 룬 새김터(R1_03)가 큰길에서 그대로 보인다.** 1×1 방이라 카메라에 방 전체가 보이고, 오람이 있는 위층으로 가는 통과 발판 계단이 큰길 바로 옆에 있다. 깨어나서 오른쪽으로 걷기만 하면 만난다.

목표: **지형만 봐도 구역을 알 수 있고, 같은 구역 안에서도 방마다 싸우는 방식이 다르게**. 새김터는 **단서를 보고 찾아야** 만나게.

## 1. 바꾸지 않는 것 (모든 수정에 공통)

방을 고칠 때 아래는 **그대로 둔다**. 예외는 7장(R1_03)과 9장(잠금 전투방의 아레나 문·숨구멍 추가)뿐이다. 그 밖에 옮겨야 하면 이유를 적고 사용자에게 먼저 묻는다.

| 항목 | 이유 |
|---|---|
| `id`, `size`, `map_cell`, `exits`(rect·to·to_exit) | 지도·방 연결·출구 짝 검사 |
| 영구 id (`breakables`·`gates`·`switches`·`items`·`seat`·`safe_zones`의 id) | 세이브가 id로 기억한다. **위치는 옮겨도 되지만 id는 바꾸지 않는다** |
| `safe_zones` 영역과 `seat` | 안전지대 간격·보스 런백 |
| `air_vents` 개수 | 숨 예산 (위치는 같은 구간 안에서만 조금 이동 가능) |
| `breath_gates`, `breath_zones`, `water`의 크기 | 숨 배율 구간 길이 = 숨 예산 |
| 보스 아레나(`*_B*`) | 11.1 원칙 9 |
| 숨 게이트 방 (R1_G1·G2, R2_05·10, R4_05, R6_G1~G3) | 통로 길이를 7.6 목표 1에 맞춰 둠 → T58에서 본다 |
| 정예 아레나 (R2_08, R4_07) | 아레나 잠금·트리거 위치 |
| 안전지대 방 (R1_01·04·09, R2_01·04·09, R3_01·05·09, R4_01·04·09, R5_01·04·09) | 쉼터. 손대지 않는다 (R1_03은 7장) |
| 기믹 시연 방 (R2_07 쇠뇌 회랑, R4_10·R5_05 긴 구덩이) | 기믹 하나를 보여 주는 방 |
| R0 광산 4방 | 도입부 연출(트리거) 고정 |

**지나가는 시간**: 필수 경로 방은 고친 뒤 지나가는 시간이 **지금보다 ±20% 안**이어야 한다. 숨의 룬 전 R1 구간은 `R1_SEGMENT_MAX`(15초)를 넘으면 안 된다. 시간은 스톱워치로 잰다. **F6 기록은 남기지 않는다** (`data/breath_budget.json`은 T58 측정용).

## 2. 좌표·이동·적 동작 (코드 기준 사실)

### 2.1 좌표 규칙

- 방 좌표는 **왼쪽 아래가 (0, 0), y는 위로 증가**. 1화면 = 1280×720.
- `platforms` `[x, y, w, h, kind]` = 왼쪽 아래 모서리 + 크기. 바닥은 보통 `[0, 0, 방폭, 64]` → 걷는 높이 y = 64.
- `spawns` `[종류, x, y]`와 `objects`의 (x, y) = **발 밑 가운데**. 발판 위에 세우려면 y = 발판 윗면(`y + h`).
- `safe_points` = 가시·구덩이에 빠졌을 때 돌아오는 자리. **발판 윗면 위**여야 한다.

### 2.2 이동 수치

발판 간격은 **안정적으로 되는 값**(괄호 안은 이론상 최대)을 쓴다.

| 동작 | 높이 | 가로 거리 | 쓸 수 있는 구역 |
|---|---|---|---|
| 플레이어 몸 | 56 | 28 | — |
| 꾹 누른 점프 | **≤ 180** (214) | 같은 높이 틈 **≤ 260** (≈ 310) | 전부 |
| 곡괭이 위 공격 | 머리 위 85까지 닿음 | 폭 60 | 전부 |
| 점프 + 공중 대시 | — | **≤ 440** (≈ 525) | 굴착의 룬 이후 |
| 벽점프 | 마주 보는 벽 사이 폭 **120~260**이면 계속 오름 | — | R3부터 (버팀) |
| 결정 디딤(이단 점프) | **≤ 360** (≈ 428) | **≤ 480** | R4부터 (결정) |
| 돌파 | 수평 직선, 벽에 닿을 때까지 | 땅·벽 출발이면 사실상 무제한 (Lv3는 공중 출발) | R5부터 (돌파) |
| ↓+Z | 통과 발판 아래로 내려감 | — | 전부 |

- **천장 높이**: 점프할 수 있는 통로는 바닥에서 천장까지 **≥ 260**. 점프를 막는 "낮은 천장"은 **120~160** (서서 지나가고, 점프하면 머리를 박는다).
- **계단 한 칸**: 120~160. 180을 넘는 단은 의도한 "점프 시험"에만.
- **통과 발판 길이는 섞는다** — S 120 / M 200 / L 320 / XL 480 이상. 한 방에 같은 길이를 3개 넘게 두지 않는다.
- **카메라**: 방 안에서 플레이어를 따라가고, ↑를 누르고 있으면 위로 180 더 본다. 바닥(y 64)에 서 있으면 y 0~900까지 보일 수 있다.

### 2.3 적 동작 (지형을 짤 때 알아야 할 것)

| 적 | 몸 (w×h) | 지형과 관련된 동작 | 지형 규칙 |
|---|---|---|---|
| 공통 | — | 감지 = 가로 거리 안 + **같은 높이 ±200**, 벽 너머는 못 봄 (10.1). 안전지대 안으로 안 들어옴 | 위층에 둔 적은 **플레이어가 지나가는 높이에서 200 안**이어야 싸움이 된다 |

## 3. 구역별 진입 능력과 지형 문법

### 3.0 필수 경로가 요구해도 되는 이동

| 구역 | 요구해도 되는 이동 | 주의 |
|---|---|---|
| R1 | 점프, 포고 | B1(대시)과 새김터는 순서 자유 → **점프만으로** 오르내린다 |
| R2 | 점프, 포고 | 진입 조건이 숨 Lv1뿐 → **대시 없이** 통과. R2_02·03·06·11은 반격의 시련 전 → **반사가 필요한 배치 금지** |
| R3 | + 벽점프 | 대시는 있다고 가정하지 않는다 |
| R4 | + 이단 점프 | 물 안은 느려지고 중력이 약해진다 |
| R5 | + 돌파 | 그림자 질풍은 B5 뒤 |
| R6 | 전부 | 최종 구역 |

능력이 더 필요한 길은 **선택 경로**(숨은 벽·광맥벽·흙벽 뒤 보상)로만 둔다.

각 구역은 **대표 지형 2~3개**를 그 구역 전투방에 반복해서 쓴다. 다른 구역의 대표 지형은 가져오지 않는다.

### 3.1 R1 잊힌 회랑 — 무너진 석조 회랑 (청회색)

- **무너진 석판**: 바닥에서 100~160 올라온 넓은 solid 단(폭 300~600). 위아래 두 층 길.
- **잔해 더미**: 높이 60~120, 폭 80~200의 낮은 solid 덩어리 2~3개 연속.
- **내려앉은 천장**: 천장에서 내려온 solid 덩어리로 낮은 천장(120~160). 점프 대신 패링으로 상대하는 곳.
- 적: 벌레는 **석판 위를 왕복**, 박쥐는 두 층 사이.

```
 천장 ███████████████████████████████████████████
                         ▓▓▓▓▓▓▓▓ ← 내려앉은 천장 (낮은 통로)
        ═════════════               ▄▄  ▄▄▄  ▄  ← 잔해 더미
 바닥 ██▀▀▀▀▀▀▀▀▀▀▀▀▀██████████████████████████████
        ↑ 무너진 석판 (2층 길), 벌레가 위를 왕복
```

### 3.2 R2 이끼 동굴 — 습한 동굴·거대 버섯 (녹색)

- **버섯갓**: 통과 발판을 S·M·L로 섞어 높이가 다른 군락으로 쌓는다 (갓 3~5개가 한 덩어리).
- **이끼 둔덕**: 높이 40~120 단을 2~3개 이어 바닥이 오르내리게. 평평한 구간이 600을 넘지 않게.
- **포자 웅덩이**: 포자 지대·포자 버섯은 움푹한 곳에, 지나갈 길은 그 위 버섯갓으로.
- **늘어진 덩굴 천장**: 천장에서 내려온 solid 덩어리 아래 = 덩굴 매복충 천장 매복 자리.
- **가시꽃 (반사 전)**: 가시꽃과 같은 높이의 길 중간에 **solid 버섯 밑동(높이 ≥ 60, 폭 40~80)**을 1~2개 둔다. 가시를 밑동 뒤에서 막고 쿨다운(2초) 사이에 다가간다.

```
          ═══              ═════════        ▓▓▓▓ ← 덩굴 천장 (아래 매복충)
     ═══════      ═══           ══
  ▄▄▄▄          ▄▄▄▄▄▄▄     ▐▌ ← 밑동  ✿ 가시꽃 ═══════
 ████▀▀▀▀▀▀▀████▀▀▀▀▀▀▀▀██▒▒▒▒▒▒▒▒▒▒▒██████████
   둔덕          둔덕        ↑ 포자 웅덩이 (움푹)
```

### 3.3 R3 수정 광맥 — 수정 기둥·반사광 (보라)

- **수정 기둥**: 폭 48~80, 높이 300~500의 가는 solid 기둥. 두 기둥 사이 폭 120~260 = **벽점프 굴뚝**.
- **기둥 위 보상**: 결정 숨주머니·광석은 기둥 꼭대기에.
- **긴 시야 + 기둥 엄폐**: 유생·술사는 조준해서 쏘므로, 넓은 공간에 두고 사이에 기둥을 세워 **기둥에서 기둥으로 다가가게**.
- 통과 발판은 줄이고 기둥·벽으로 오른다.

```
        ▐▌          ▐▌  ◆         ▐▌
   ▐▌   ▐▌    ▐▌    ▐▌ ▐▌         ▐▌   ★ 술사
   ▐▌   ▐▌    ▐▌    ▐▌ ▐▌   ▐▌    ▐▌ ████████
 ██▐▌███▐▌████▐▌████▐▌█▐▌███▐▌████▐▌█████████
   기둥 엄폐 → 벽점프 굴뚝(◆ = 숨주머니)
```

### 3.4 R4 침수 신전 — 물에 잠긴 신전 (청록)

- **높은 신전 바닥 + 물 구덩이**: 바닥은 지금처럼 y 200의 돌바닥, 사이를 물 구덩이가 끊는다. 구덩이 폭 **260~480** (한 번 점프로는 안 되고 이단 점프면 된다).
- **잠긴 기둥 열**: 물속 기둥 그루터기(폭 60, 윗면은 수면 바로 위)를 징검다리로. 거머리가 사이에서 튀어오른다.
- **골렘 전투장**: 골렘은 점프하지 않고, 충격파는 **벽·발판 끝에서 사라진다**. 그래서
  - 골렘과 싸우는 바닥은 **턱 없이 평평하게 600 이상** (충격파가 끝까지 굴러와야 점프로 넘는 연습이 된다).
  - 위에 **짧은 통과 발판(S, 높이 140~200)** 1~2개 = 잠깐 피하는 곳. 골렘이 따라오지 못하니 내려와야만 칠 수 있다.
  - 계단·제단은 전투장 **양 끝에만** (가운데 두면 충격파가 거기서 끊긴다).
- 대칭 구조를 쓴다.

```
     ▄▄▄                    ═══                 ▄▄▄
  ▄▄▄███      ═══     (골렘 전투장, 평평)      ███▄▄▄  ← 끝에만 제단
 ████████████████~~▐▌~~▐▌~~████████████████████████████
               ↑ 물 + 잠긴 기둥, 거머리
```

### 3.5 R5 그림자 둥지 — 검은 고치·실 (남색)

- **매달린 고치**: 천장에서 늘어진 solid 덩어리(폭 120~240). 아래 = 매복충 천장 매복, 위 = 착지점.

## 4. 방별 수정 목록 (지형 + 적)

## 5. 적 보강 규칙

4장 표의 마릿수는 아래 규칙으로 정했다. 위치를 옮기거나 다른 방에 더할 때도 이 규칙을 지킨다.

1. **쉬운 적만 늘린다** — 벌레·박쥐·거머리·매복충, R5·R6은 사마귀까지. 원거리 적은 R3_03 유생 1마리만 더한다.
2. **어려운 지형 위에** 둔다 — 짧은 발판 위의 벌레, 천장 매복, 좁은 발판 위의 사마귀.
3. **목표**: 1×1 ≈ 2, 2×1 ≈ 3, 1×2 ≈ 3, 2×2 ≈ 4, 3×1 ≈ 4. 10.5 "한 화면에 2~4"에 맞춘 값이다.
4. **덜 넣는 방** (10.5 우선):
   - 새 적이 **처음 나오는 방**: 새 적은 혼자 보이게, 다른 적은 다른 화면에.
   - **안전지대 바로 옆 방**(안전지대가 있는 방 포함): 그대로 두거나 +1까지. R1_02·06·08, R2_03·06, R3_02·04·06, R4_02·06, R5_02·03·06·10, R6_02·03.
   - **숨 게이트 방, 보스·정예 아레나, 기믹 시연 방**: 더하지 않는다.
   - **숨의 룬 전 R1**(용량 25): +1까지.
   - **잠금 전투방**(9장)의 잠금 웨이브는 이 규칙 3·4의 예외다. 대신 9장 규칙을 따른다.
5. 한 방에 원거리 공격 적은 **최대 2종**.
6. 숨구멍 근처에는 적을 두어 **숨을 얻으려면 싸우게** 해도 된다 (10.5). 단 숨구멍 바로 위에 두지 않는다.
7. 일반 적은 방에 다시 들어올 때마다 재생성되므로, 적이 늘면 광석 파밍량도 는다 → T20 광석 경제에서 확인.

## 7. R1_03 숨은 새김터 — 단서를 보고 찾게

### 7.1 문제

R1_03은 1×1이라 카메라에 방 전체가 보인다. 깨어나서(R1_01) 오른쪽으로 걸으면 R1_03 큰길에서 위층의 오람이 바로 보이고, 큰길 오른쪽 끝의 통과 발판 계단을 오르면 균열벽 하나만 깨고 닿는다. 명세 7.5는 "숨겨져 있되, 막혀서 그만두지 않게"를 요구한다.

### 7.2 지켜야 할 명세

- 새김터는 **허브 방(R1_04)과 출구로 바로 이어진 방**에 있다 (검증 스크립트 검사).
- 허브 안전지대 → 새김터 **`CARVER_FROM_HUB_MAX`(10초) 이하**, 길에 적·가시 없음 (12.4).
- 숨은 벽은 **균열벽(`crack`)** 이고 바람 단서가 그려진다 (7.5-1, 18장 59번). 허브를 오갈 때마다 그 앞을 지나친다 (7.5-4).
- 석판 2개(`tablet_r1_carver_a`·`_b`)의 단서, 보름 힌트(숨막이 갱 기절 횟수)는 그대로 쓴다.
- 새김터로 가는 길에 광석 60 이상 (7.4) → 큰길의 `chunk_a`·`chunk_b`는 큰길에 둔다.

### 7.3 바꾸는 방법 — 1×2로 늘려 새김터를 위 화면으로

지도 칸 [7, 7]이 비어 있다 (R1_05는 [8, 7]). R1_03을 `size [1, 2]`(높이 1440), `map_cell [7, 6]` 그대로 둔다.

```

        ║                                    ║
  L2 →  ║  ⌂오람   ▭의자      (새김터 = 안전지대)  ║   ← 위 화면: 큰길에서는 안 보임
```

## 9. 잠금 전투방 — 구역마다 1~2개

### 9.1 무엇

방에 들어서 트리거를 밟으면 **출구가 돌문으로 닫히고**, 평소보다 많은 적이 **웨이브로** 나온다. **모두 잡아야 문이 열린다.** 구역마다 1~2개, 일반 전투방 사이에서 "여기서는 버텨야 한다"는 박자를 만든다.

- 정예 아레나(R2_08, R4_07)와 같은 **아레나 문**(`gates` 종류 `arena`, 11.2)을 쓴다. 다른 점은 보스·정예 대신 **일반 적 웨이브**를 다 잡으면 열린다는 것.
- 처음 깨기 전에는 들어올 때마다 잠긴다. **한 번 깨면 영구히 잠기지 않는다** (되돌아올 때마다 갇히면 길찾기가 지친다). 깬 뒤에는 일반 spawn만 평소처럼 재생성된다.
- 처음 깰 때 보상: 광석 덩어리 1개(또는 `LOCKDOWN_REWARD_ORE`만큼 광석). R3_12는 원래 있던 보상방 아이템이 보상이다. 양은 T20 광석 경제에서 정한다.

### 9.2 고른 방

고른 기준: **새 적이 처음 나오는 방이 아님**, **안전지대 바로 앞뒤 방이 아님**(10.5), 숨 게이트·보스·정예 아레나·기믹 시연 방이 아님, 안전지대에서 2방 안(재도전이 빠르게).

### 9.3 장치 (코드)

정예 아레나의 `Arena` 트리거(`systems/script.py`)를 본떠 **`Lockdown` 트리거**를 새로 만든다. 문 열고 닫기는 `room.arena_gates`의 `close()`/`open()`을 그대로 쓴다.

- **방 JSON**
  - `gates`: 잠기는 출구마다 `[x, y, w, h, "arena", "lock_l"]` (정예 아레나 R2_08과 같은 모양, 출구 rect 바로 안쪽).
  - `triggers`: `[x, y, w, h, "lockdown", "lock_r3_07"]` — 마지막 값이 **영구 id** (세이브가 기억).
  - `lockdown`: `{"id": "lock_r3_07", "waves": [[["worm", x, y], ...], [...]]}` — 웨이브마다 spawn 목록 (형식은 `spawns`와 같음).
- **동작**
  1. 트리거에 들어가면: 이미 깬 id면 아무것도 안 함. 아니면 아레나 문을 닫고(큰 소리 + 작은 화면 흔들림) 1웨이브를 낸다.
  2. 웨이브 적은 나타나기 전 **0.6초 예고**(바닥 먼지·그림자) 뒤 생긴다. 플레이어에게서 **200 이상** 떨어진 자리만 쓴다.
  3. 웨이브의 적이 모두 죽으면 1초 쉬고 다음 웨이브. 마지막 웨이브까지 죽으면 문이 열리고, id를 `world.state.lockdowns_cleared`(새 set, 세이브 포함)에 넣고 보상을 떨어뜨린다.
  4. 잠긴 동안 방 안의 기존 `spawns` 적도 "다 잡아야" 대상에 넣는다 (트리거 시점에 살아 있는 적).
  5. 플레이어가 죽으면 문을 열고 웨이브를 지운다 (앉는 자리에서 다시 시작, 다음에 들어오면 처음부터).
- `validate_rooms.py`: `lockdown` id ↔ 트리거 id 짝, 잠금 방에 `arena` 문이 출구 수만큼, 웨이브 spawn이 발판 위, 잠기는 구역 안에 `air_vents` 1개 이상.
- 이 장치는 T66 명세의 파일 범위(`data/rooms`, `breakable.py`) 밖이다 (`systems/script.py`, `systems/world.py`·세이브, `tools/validate_rooms.py`, 필요하면 `config.py`). **T66을 시작하기 전에 명세 T66 항목에 이 범위를 더할지 사용자에게 묻는다.**

### 9.4 배치 규칙

1. **마릿수**: 웨이브 합계 1×1 5~7, 2×1·1×2 5~6, 2×2·3×1 6. **한 화면에 동시에 4마리 이하** (10.5 "한 화면 2~4"의 위쪽 끝).
2. **웨이브는 2개**(R3_12만 3개). 1웨이브는 쉬운 적만, 2웨이브에 그 구역의 조금 더 까다로운 적 1마리.
3. **쉬운 적만** — 5장 규칙 1과 같다. 정예·골렘·그림자 사냥꾼은 웨이브에 넣지 않는다. 원거리 적은 방 전체에서 최대 2종.
4. **그 방에서 처음 나오는 적은 쓰지 않는다** (첫 등장은 일반 방에서 혼자).
5. **지형**: 잠기는 구역은 그 구역 대표 지형(3장)으로 짜되, **피할 자리**가 있어야 한다 — 2층 발판, 엄폐 기둥, 짧은 통과 발판. 가시·구덩이는 잠기는 구역 안에 두지 않는다 (몰려서 떨어지는 죽음 방지).
6. **숨**: 잠기는 구역 안에 숨구멍 **1개 이상** (없으면 하나 더한다 = 1장 "숨구멍 개수 유지"의 예외). 숨구멍 근처에 웨이브를 내어 "숨을 얻으려면 싸우게" (10.5). 전투 예상 시간 **30초 안팎**. 숨 수치는 T58에서 이 전투를 포함해 잰다.
7. 잠기는 구역 밖의 길(출구까지)은 짧게. 문이 열린 뒤 바로 나갈 수 있게.

### 9.5 지나가는 시간

잠금 전투방은 1장 "지금 ±20%" 시간 규칙의 **예외**다. 대신 처음 깰 때 잠금 전투가 **30~40초** 안에 끝나는지 3판 재서 적는다 (스톱워치). 깬 뒤 다시 지나갈 때는 ±20% 규칙을 그대로 지킨다.

### 9.6 잠금 전투방을 고친 뒤 확인할 것

- [ ] 트리거를 밟으면 모든 출구 문이 닫히고, 웨이브가 예고 뒤 플레이어에게서 떨어진 곳에 나온다
- [ ] 모든 적을 잡으면 문이 열리고 보상이 나온다. 방을 나갔다 들어와도 **다시 잠기지 않는다** (세이브 후 다시 불러와도)
- [ ] 잠긴 동안 죽으면 문이 열리고, 다시 오면 처음 웨이브부터
- [ ] 한 화면에 동시에 적 4마리 이하, 원거리 2종 이하
- [ ] 잠기는 구역 안에 숨구멍이 있고, 숨 용량이 그 구역 진입 기준(3.0)일 때 질식 없이 깰 수 있다 (3판)
- [ ] 적이 문 밖이나 발판 안에 나오지 않는다
