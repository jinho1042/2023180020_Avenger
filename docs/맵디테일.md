# 맵 디테일 — 전투방 지형 가이드

> **무엇**: 전투방의 발판·지형·적 배치를 구역 특징에 맞게 다시 짜기 위한 작업 기준과 방별 수정 목록.
> **언제**: T58(숨 예산 확정) **전에** 끝낸다. T58은 방을 지나가는 시간을 재서 숨 수치를 확정하므로, 그 뒤에 지형을 바꾸면 다시 재야 한다.
> **위치**: 명세(`개발문서v3.5.md`)는 동결(0장 16번)이라 고치지 않는다. 이 문서는 명세 12.4(방 설계 규칙)·10.5(적 배치 규칙)를 **지형 쪽으로 구체화**한 보조 문서이고, 명세와 부딪히면 명세가 이긴다.
> **기준 데이터**: 2026-11-18 `data/rooms/` (전체 방 목록·출구는 `docs/전체맵.md`).

---

## 0. 왜 필요한가 (현재 상태 진단)

보스방·게이트방을 뺀 전투방 29개의 발판을 그려 비교한 결과:

1. **가로방 절반이 같은 틀**이다 — "평평한 바닥 + 200px 안팎 통과 발판 2~3개 + 낮은 박스 1개".
   R1_02, R1_07, R2_02, R3_02, R3_06, R4_03, R5_02, R5_06, R5_10, R6_02, R6_03.
   통과 발판이 바닥 근처에만 떠 있어서 전투가 사실상 평지 싸움이 된다.
2. **수직방 5개가 같은 사다리**다 — 좌우로 번갈아 놓인 통과 발판(폭 200~340)을 타고 오르내린다.
   R1_06, R3_03, R4_06, R5_03, R5_07. 구역이 달라도 모양이 같다.
3. **같은 묶음을 복사한 흔적**이 있다 — "왼쪽 위 선반(x 40, y 440, 폭 400~500) + 그 오른쪽 균열벽 + 통과 발판 계단 2개(≈600,300 / ≈588,464) + 선반 위 광석 덩어리".
   R1_07, R1_08, R2_02, R2_06, R2_11 (좌표까지 거의 같다).
4. **적이 거의 바닥(y = 바닥 높이)에만** 있고, 방 하나(2화면)에 1~2마리다.
   명세 10.5는 "한 화면에 적 2~4", "쉬운 적을 어려운 지형 위에"를 요구한다.
5. 그래서 구역마다 바뀌는 건 **적 종류와 기믹**뿐이고, 지형만 보면 어느 구역인지 구분되지 않는다.

이 문서의 목표: **지형만 봐도 구역을 알 수 있고, 같은 구역 안에서도 방마다 싸우는 방식이 다르게** 만든다.

## 1. 바꾸지 않는 것 (모든 수정에 공통)

방을 고칠 때 아래는 **그대로 둔다**. 옮겨야 하면 이유를 적고 사용자에게 먼저 묻는다.

| 항목 | 이유 |
|---|---|
| `id`, `size`, `map_cell`, `exits`(rect·to·to_exit) | 지도·방 연결·출구 짝 검사 |
| 영구 id (`breakables`·`gates`·`switches`·`items`·`seat`·`safe_zones`의 id) | 세이브(`world_state`)가 id로 기억한다. **위치는 옮겨도 되지만 id는 바꾸지 않는다** |
| `safe_zones` 영역과 `seat` | 안전지대 간격·보스 런백 |
| `air_vents` 개수 | 숨 예산 (위치는 같은 구간 안에서만 조금 이동 가능) |
| `breath_gates`, `breath_zones`, `water`의 크기 | 숨 배율 구간 길이 = 숨 예산 |
| 보스 아레나(`*_B*`) | 11.1 원칙 9 (평지 + 발판 최대 2개) |
| 숨 게이트 방 (R1_G1·G2, R2_05·10, R4_05, R6_G1~G3) | 통로 길이를 7.6 목표 1에 맞춰 둠 → T58에서 같이 본다 |
| 정예 아레나 (R2_08, R4_07) | 아레나 잠금·트리거 위치 |
| 안전지대 방 (R1_01·03·04·09, R2_01·04·09, R3_01·05·09, R4_01·04·09, R5_01·04·09) | 적이 없는 쉼터. 손대지 않는다 |
| R0 광산 4방 | 도입부 연출(트리거) 고정 |

**지나가는 시간**: 필수 경로 방은 고친 뒤 지나가는 시간이 **지금보다 ±20% 안**이어야 한다. 특히 숨의 룬 전 R1 구간은 `R1_SEGMENT_MAX`를 넘으면 안 된다.

## 2. 몸 크기와 이동 수치 (발판 간격의 기준)

`config.py` 기준. 발판 간격은 **안정적으로 되는 값**(괄호 안은 이론상 최대)을 쓴다.

| 동작 | 높이 | 가로 거리 | 쓸 수 있는 구역 |
|---|---|---|---|
| 플레이어 몸 | 56 | 28 | — |
| 짧게 톡 친 점프 | ≈ 43 | — | 전부 |
| 꾹 누른 점프 | **≤ 180** (214) | 같은 높이 틈 **≤ 260** (≈ 310) | 전부 |
| 점프 + 공중 대시 | — | **≤ 440** (≈ 525) | 굴착의 룬 이후 |
| 벽 매달리기·벽점프 | 마주 보는 벽 사이 폭 **120~260**이면 무한히 오름 | — | R3부터 (버팀) |
| 결정 디딤(이단 점프) | **≤ 360** (≈ 428) | **≤ 480** | R4부터 (결정) |
| 돌파 | 수평 직선, 벽까지 | 땅·벽에서 출발하면 사실상 무제한 (Lv3는 공중 출발) | R5부터 (돌파) |
| ↓+Z | 통과 발판 아래로 내려감 | — | 전부 |

규칙:
- **천장 높이**: 위로 점프할 수 있는 통로는 바닥에서 천장까지 **≥ 260**. 점프를 막는 "낮은 천장"은 **120~160** (서서 지나갈 수 있고 점프는 머리를 박는다).
- **계단 한 칸**: 120~160. 180을 넘는 단은 "점프 시험"이므로 의도한 곳에만 둔다.
- **통과 발판 길이는 섞는다** — S 120 / M 200 / L 320 / XL 480 이상. 한 방에 같은 길이를 3개 넘게 두지 않는다.
- **떨어지면 처음부터 다시 올라가야 하는 구간**은 한 방에 하나까지. 아래에 받쳐 주는 발판이 없으면 `safe_points`가 아니라 지형으로 해결한다.

## 3. 구역별 진입 능력 — 필수 경로가 요구해도 되는 것

| 구역 | 필수 경로에서 요구해도 되는 이동 | 주의 |
|---|---|---|
| R1 | 점프, 포고 | B1(대시)과 새김터는 순서 자유 → R1_02·06·07·08은 **점프만으로** 오르내린다 |
| R2 | 점프, 포고 | 진입 조건이 숨 Lv1뿐이라 **대시 없이** 통과할 수 있어야 한다. R2_02·03·06·11은 반격의 시련 전이므로 **반사가 필요한 배치 금지** (10.2) |

## 4. 구역별 지형 문법

각 구역은 **대표 지형 2~3개**를 정해 그 구역 전투방에 반복해서 쓴다. 다른 구역의 대표 지형은 가져오지 않는다.

### R1 잊힌 회랑 — 무너진 석조 회랑 (청회색)

- **무너진 석판**: 바닥에서 100~160 올라온 넓은 solid 단(폭 300~600). 위아래 두 층으로 걷는 길을 만든다.
- **잔해 더미**: 높이 60~120, 폭 80~200의 낮은 solid 덩어리를 2~3개 연달아. 바닥을 울퉁불퉁하게.
- **내려앉은 천장**: 천장에서 내려온 solid 덩어리로 낮은 천장 구간(120~160)을 만든다. 점프로 넘기 대신 패링으로 상대해야 하는 곳.
- 적: 갱도 벌레는 발판 끝에서 돌아서므로 **석판 위를 왕복**시킨다 (쉬운 적 + 어려운 지형). 박쥐는 두 층 사이 빈 공간.

```
 천장 ███████████████████████████████████████████
                         ▓▓▓▓▓▓▓▓ ← 내려앉은 천장 (낮은 통로)
        ═════════════               ▄▄  ▄▄▄  ▄  ← 잔해 더미
 바닥 ██▀▀▀▀▀▀▀▀▀▀▀▀▀██████████████████████████████
        ↑ 무너진 석판 (2층 길), 벌레가 위를 왕복
```

### R2 이끼 동굴 — 습한 동굴·거대 버섯 (녹색)

- **버섯갓**: 통과 발판을 S·M·L로 섞어 **높이가 다른 군락**으로 쌓는다. 갓 3~5개가 한 덩어리.
- **이끼 둔덕**: 바닥이 완만하게 오르내린다 (높이 40~120 단을 2~3개 이어 붙임). 평평한 바닥 구간이 600을 넘지 않게.
- **포자 웅덩이**: 포자는 낮은 곳에 고인다. 포자 지대·포자 버섯은 **움푹한 곳**에, 지나갈 길은 그 위 버섯갓으로.
- **늘어진 덩굴 천장**: 천장에서 내려온 solid 덩어리 아래에 덩굴 매복충(천장 매복)을 둔다.
- 반사 전: 가시꽃 앞에는 **가시를 막아 주는 solid 지붕**(통과 발판은 막지 못한다고 가정)을 두고, 그 아래로 다가가게 한다.

```
          ═══              ═════════        ▓▓▓▓ ← 덩굴 천장 (아래 매복충)
     ═══════      ═══           ══
  ▄▄▄▄          ▄▄▄▄▄▄▄                  ═══════
 ████▀▀▀▀▀▀▀████▀▀▀▀▀▀▀▀██▒▒▒▒▒▒▒▒▒▒▒██████████
   둔덕          둔덕        ↑ 포자 웅덩이 (움푹)
```

### R3 수정 광맥 — 수정 기둥·반사광 (보라)

- **수정 기둥**: 폭 48~80, 높이 300~500의 가는 solid 기둥. 두 기둥 사이 폭 120~260이면 **벽점프 굴뚝**이 된다.
- **기둥 위 보상**: 결정 숨주머니·광석은 기둥 꼭대기에.
- **긴 시야**: 수정 유생·술사는 거리를 유지하므로 **멀리서 서로 보이는 넓은 공간**에 두고, 사이에 기둥을 세워 **기둥에서 기둥으로 엄폐하며 다가가게** 한다.
- 통과 발판은 줄이고 기둥·벽으로 오른다.

```
        ▐▌          ▐▌  ◆         ▐▌
   ▐▌   ▐▌    ▐▌    ▐▌ ▐▌         ▐▌   ★ 술사
   ▐▌   ▐▌    ▐▌    ▐▌ ▐▌   ▐▌    ▐▌ ████████
 ██▐▌███▐▌████▐▌████▐▌█▐▌███▐▌████▐▌█████████
   기둥 엄폐 → 벽점프 굴뚝(◆ = 숨주머니)
```

### R4 침수 신전 — 물에 잠긴 신전 (청록)

- **높은 신전 바닥 + 물 구덩이**: 바닥은 지금처럼 y 200의 돌바닥, 그 사이를 물 구덩이가 끊는다. 구덩이 폭은 **260~480** (한 번 점프로는 안 되고 이단 점프면 된다).
- **잠긴 기둥 열**: 물속에 기둥 그루터기(폭 60, 수면 바로 위)를 늘어놓아 징검다리를 만든다. 거머리가 사이에서 튀어오른다.
- **제단 계단**: 3~4단짜리 solid 계단. 유적 골렘의 충격파(바닥을 따라 가는 낮은 투사체)를 **단 위로 피하는** 지형.
- 대칭 구조를 쓴다 (신전 느낌).

```
           ▄▄▄▄                         ▄▄▄▄
        ▄▄▄████▄▄▄    ▐▌  ▐▌  ▐▌     ▄▄▄████▄▄▄  ← 제단 계단
 ███████████████████~~██~~██~~██~~████████████████
                     ↑ 물 + 잠긴 기둥(징검다리), 거머리
```

### R5 그림자 둥지 — 검은 고치·실 (남색)

- **매달린 고치**: 천장에서 늘어진 solid 덩어리(폭 120~240). 아래는 덩굴 매복충(천장 매복) 자리, 위는 착지점.
- **실 다리**: 폭 120~160의 **좁은** 발판을 넓은 빈 공간 위에 띄운다. 쌍낫 사마귀의 빠른 베기와 그림자 사냥꾼의 뒤로 순간이동을 좁은 발 디딤에서 받아야 한다.
- **낮은 통로**: 천장 120~160인 좁은 굴. 그림자 사냥꾼을 점프로 넘을 수 없게 해서 패링을 쓰게 한다.
- **돌파 구간**: 땅에서 출발해 가시·구덩이 위를 돌파로 건너는 긴 수평 구간. 끝에 벽을 둬서 멈추게 한다.

```
 ████▓▓▓██████▓▓▓▓████████████████████▓▓▓█████
     ▓▓▓      ▓▓▓▓  ← 매달린 고치 (아래 매복충)  ▓▓▓
           ══         ══        ══          ← 실 다리 (좁음)
 ████████▲▲▲▲▲▲▲▲▲▲▲▲▲▲▲▲▲▲▲▲▲▲▲▲▲▲▲▲▲▲████████
   돌파 출발 →→→→→→→→→→→→→→→→→→→→→→→→→→→ 벽
```

### R6 왕의 묘실 — 금빛 석조 (황토)

- **대칭 회랑**: 방 가운데를 기준으로 좌우 대칭. 위층 회랑(solid, 폭 600 이상)과 아래층 홀.
- **기둥 열**: 일정 간격(300~400)의 굵은 기둥(폭 80~120, 높이 200~300). 사이사이가 전투 칸.
- **계단식 단상**: R4의 제단보다 넓고 낮은 단(높이 80~100).
- 앞 구역의 지형을 **한 방에 하나씩 섞어** 졸업 시험으로 쓴다 (기둥 굴뚝, 실 다리 등). 단, B6 앞(R6_03)은 런백 때문에 단순하게.

## 5. 방별 수정 목록

우선순위: **높음** = 0장 1·2번(같은 틀)에 해당 / **중간** = 부분 수정 / **낮음** = 이미 개성이 있어 손만 봄 / **유지** = 고치지 않음.

### 5.1 한눈에

| 방 | 크기 | 지금 | 바꿀 형태 | 우선순위 |
|---|---|---|---|---|
| R1_02 | 2×1 | 평지 + 박스 2 | 무너진 석판 2층 | 중간 |
| R1_06 | 1×2 | 사다리 (내려감) | 무너진 승강 갱 | **높음** |
| R1_07 | 2×1 | 평지 + 박스 + 복사 선반 | 낮은 천장 회랑 | **높음** |
| R1_08 | 1×1 | 봉인문 + 복사 선반 | (선반 모양만) | 낮음 |
| R1_10 | 1×1 | 서쪽 수직 갱 | — | 유지 |
| R2_02 | 2×1 | 평지 + 박스 + 복사 선반 | 버섯 숲 + 가시 지붕 | **높음** |
| R2_03 | 2×2 | 큰 덩어리 + 포자 + 계단 | 포자 웅덩이 강조 | 낮음 |
| R2_06 | 2×1 | 계단 + 큰 박스 + 복사 선반 | 덩굴 천장 | **높음** |
| R2_11 | 1×1 | 선반 + 복사 계단 | 버섯 계단 | 중간 |
| R3_02 | 2×1 | 평지 + 박스 2 | 수정 기둥 숲 | **높음** |
| R3_03 | 1×2 | 사다리 (올라감) | 벽점프 굴뚝 | **높음** |
